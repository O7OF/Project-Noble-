# Reach mod playtest bugs (Tyler, 2026-11-10 ~15:00 ET)

Mods tested through Noble: Civility (third-person, ODST-based), Prophet's Hand (campaign, incl. bonus mission
"Rebel Strike"), a campaign mod with missions Trebuchet / Spring Cleaning, Trooper Firefight, Trepanation (custom game),
and one Firefight mod with a custom map. All of them work in MCC. Mods come from Steam Workshop (976730) or `data\mods`
(see `src/ui/ModCatalog.cpp`, `VFS::SetActiveMod`).

"Likely cause" lines are first guesses from the code layout, NOT verified. Check each one before fixing.

## Priority 1: mods that don't run

### 1. Custom-map missions never finish loading (stop after 5-10 s)
- Trebuchet, Spring Cleaning (campaign), Prophet's Hand bonus mission Rebel Strike, a Firefight mod with its own map.
  Missions on stock maps in the same mods load fine (the first mission in the list worked).
- Likely cause: Noble launches by Reach map id (`BlamEngine::ResolveMapId`); a scenario that is not in Reach's own
  tables has no id, or the id/launch block does not match the mod's `.map`. Also check that the VFS serves every file
  the custom map needs from the mod folder (the `.map` itself, plus anything else the mod ships next to it).
- Get from the run: `noble-client.log` around the load (map id, the path VFS resolved, last loading-screen progress).

### 2. Trepanation (custom game) shows the main-menu background instead of the map
- Likely the same as #1 (custom map) and/or a missing game type: these mods ship their own game variants
  (ModInfo `GameModContents`, `game_variants\` in the mod folder) that must be paired with the map. Noble only lists
  `data\game_variants` and MCC's folders.
- Fix direction: read the mod's own variants in ModCatalog, list them first for that mod's maps, and pass the paired
  one by default.

### 3. Mod weapon sounds missing (SMG and starting pistol in the trebuchet mod; Prophet's Hand weapons)
- Fine in MCC. Likely cause: mods ship extra FMOD banks (`fmod\pc\sfx.<name>.fsb` + `.fsb.info`, same as the Spectre's
  `sfx.st_spectre.fsb`) and Noble/VFS does not serve or load them from the active mod folder, so the modded sound tags
  point at banks the engine never opened.
- Check: list `fmod\pc` in the mod folders; log which `.fsb` files the engine asks VFS for.

## Priority 2: menus

### 4. Pause menu doesn't pause in mods, and lags on open
- Esc in a mod does not pause the game.
- Opening the pause menu stalls (sometimes can't click Leave / Quit / Settings, or a click lands a second late). Tyler
  thinks it's the daily/weekly challenge list being built when the menu opens (`src/ui/PauseMenu.cpp`,
  `src/career/Career.cpp`).
- Fix direction: build the challenge list once (or on a worker thread) and cache it; never block the menu's first
  frame on it. Then check how pause is done in stock campaign vs. mod campaign / Firefight (it may only pause when
  the game is single-player stock).

### 5. Voice chat: V does nothing in a mod
- No voice-chat indicator when pressing V while playing a mod. Check `src/audio/VoiceChat.cpp`: is voice only started
  for online lobbies (a solo mod run has no session), or is the key/overlay not hooked in mod launches?
- Decide what V should show when there is nobody to talk to (at least "voice chat: no session").

### 6. Third-person setting: add a disclaimer
- Noble's third-person camera defaults to 50%. Mods that are already third-person by default (Civility, ODST-based)
  get the 50% applied to the weapon zoom instead of the camera distance.
- Wanted: a note next to the setting, e.g. "Mods with their own third-person camera can make this change weapon
  zoom instead; set it to Off for those mods." Better later: detect a mod's own third-person default and skip
  Noble's camera for it (`src/engine/CameraThirdPerson.cpp`).

### 7. Mods' custom loading screens are not shown
- In MCC each mod mission shows the mod's own loading picture and flavour text; Noble shows its own.
- Fix direction: ModCatalog already reads per-map images for the menu (`imageLoading`); pass the mod's loading image
  and description to `LoadScreen` for mod launches.

## Not a Noble bug / feature idea

### 8. Trooper Firefight (play as a marine)
- Class picker appears and the shield warning blinks: same in MCC, so it's the mod.
- Feature idea: the Spartan's armor colors carried over to the marine in Noble (not in MCC). Could become
  "customised marine armor" later.
