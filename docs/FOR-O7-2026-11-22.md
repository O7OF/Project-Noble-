## Needs you (network / sessions)
1. **Forge World map check for guests.** Host and guests must have the same `data\maps\forge_halo.map`. Current pack
   map: 838,799,360 bytes, SHA-256 82E125E5...0DC5 (v0.20.36). Older ones: v0.20.35 838,791,168 (AI paths, no names);
   v0.20.34 796,790,784 (no AI paths). A guest with another copy should be told to update in MODS, not join.
2. **Map variants across Forge World versions.** Not yet known whether saved map variants refer to palette positions or
   tag indices. If tag indices, rebuilding Forge World with added tags (the coming AI spawners) can make maps saved on an
   older pack load wrong objects. Being tested before the spawners ship; tell us if you know the mvar layout.
3. **AI in online games.** Guests see and fight the host's AI through the engine's own object sync (tested with 2
   players, no crash). Host-only placement. Coming: AI placed from the native Forge menu (spawner objects); these are
   placed by whoever edits, so check that guest-placed spawners create AI only on the host (the AI Battleground mod
   warns of duplicate AI when guests run its modded dll; Noble's patch is the same 6 bytes at hr+0x692CB5 and is applied
   on every client today).
4. **Dedicated server tick.** `0x61A38` (Noble's game tick) is called from `0x62A78` only for local players;
   noble-dedicated runs no engine session, so MAP AI / Firefight allies / wave pacing would need another game-thread
   hook there.
5. **Pelican doors / gear.** Scripted object function 3 (global, all Pelicans) is toggled locally with X; online sync
   untested.
