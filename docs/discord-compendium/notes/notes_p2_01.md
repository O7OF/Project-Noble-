## Missed facts
- Metallic goes dark by design: in the engines discussed, a higher "metallic" value darkens the diffuse colour toward black/environment; at 1 the colour is gone, and without an env reflection the surface reads black. Metallic is "spec colour = base colour, spec intensity = metallic slider", nothing renders true metal (gameoverload, 2023-04, general-help). Same logic from UE3/XCOM: base colour is multiplied by (1 - metal mask), spec colour is a lerp from dielectric to base (gameoverload, 2023-10). Very relevant to a black piece: a metal/spec value set too high, or an env map missing, blackens the tint.
- Quest/standard-lite shaders do not reflect the environment (r93_sniper, 2022-08); "full metal + smoothness ~0.85-0.9" in Unity Standard gives a dark mirror look unless a reflection probe exists (r93_sniper, 2022-08/2022-12). A flat black plastic-looking piece can simply be a metal=1, no-env setup.
- Mismatched shader per piece: shaders by r93_sniper/point for Spartans assume consistent channel layout across pieces (r93_sniper, 2023-07). Using a Spartan-assumption shader on an Elite/odd piece is a plausible cause of wrong colour. Also "you need a shader that appropriately works with your model" (r93_sniper, 2023-12). Reach pack armour shaders differ per piece, so a fix must be redone on each piece (omnipotentdeba, 2023-08).
- Piece-specific colour failures are common and have concrete fixes: one shoulder (Gungnir) showed no colour while others did (armageddon81, 2022-09); one knee coloured, the other not (evenmanatee887, 2022-12); chest and kneepads not coloured on ODST (evactouch, 2022-11); legs wrong colour after appending shader (Deleted User 2023-10; agentriker 2023-11); a Reach shoulder showed wrong material even after copying the working material (katyusha117, 2023-11). Fixes offered: copy the shader node tree from a working piece and re-link masks, then Ctrl+L link materials to the mirror side (exporush, 2023-02); copy the coloured node block from one coating to another piece (poet, 2023-10); swap the ASG, mask and normal textures in an appended material for the target piece's own (chiefster_4014, 2023-10); a colour-zone enable switch off defaults to zone 1 colour (gameoverload, 2023-06).
- Blank/missing mask is a suspect: helmets need mask 0 pulled from the input if blank; mask textures Non-Color; armour needs the render (camera) icon on in the outliner (gameoverload, 2022-12). If only one mask exists remove the other; render in Cycles not Eevee (gameoverload, 2022-12). Black result after choosing a colour was reported with no answer (romeo_rein, 2023-05).
- Control-map channel oddity: a tester found that in a 4-channel view green and blue looked identical and red vanished when set to Non-Color (kayhotic, 2022-12). Suggests checking whether the red/CC data is being read as colour vs data; also asked whether control maps should be sRGB or Non-Color (rennworks, 2022-10, unanswered).
- Diffuse alpha is where spec lives when no Material texture is used (gameoverload, 2022-11 and 2022-12 restating Sniper). So stripping/premultiplying alpha in an editor erases specular: chiefster_4014 describes GIMP Colors > Components > Decompose (RGB) then Recompose to kill alpha (2023-09). Also a GIMP erase/delete fills with background colour instead of transparency (hydranaught444, 2023-01) - both are ways a custom spec/alpha channel gets lost.
- Infinite elite pack colour range: pure black or bright white cannot be reached with grime sliders (pajamas007, 2023-03). Siblings to the H5 clamp in p1; points to "black" being a floor/ceiling of the shader, not only a bad input.
- Game CC logic in short: in the game the base texture is white/light grey and engine shaders recolour it (plastered_crab, 2023-08); for a replacement texture, recolour armour to white then add a simple mask (r93_sniper, 2023-05); manual route is mix colour multiply with a control channel in Fac and the texture in input 1 (tacohombre, 2023-04). Hydranaught444 notes H3 cannot do some functions Reach does, and in H3 sentinel has an unused bad CC bitmap (hydranaught444, 2022-11/2022-12); a gold spot that would not colour-change implied different masking/materials (gameoverload, 2022-11).
- Spec-related shader texture roles mentioned: one is a metallic mask (not a spec colour mask) in a combined shader, others are detail mask, spec power (gloss) map and a cubemap mask; source game not named (gameoverload, 2023-10).
- Lighting differences mimic "shine" errors: Material Preview uses a preview HDRI, Rendered uses World shader (gameoverload, 2023-10); gradient on a Chief render was glare/rim light (gameoverload, 2023-03); toon vs rendered colour shift (just_monty, 2023-09). Reach pack requires correct env/cubemap for look: the cubemap "plays a big role" (soulburnin, 2023-07) and Reach shading is similar to H3 (r93_sniper, 2023-08). A game-accurate Unity H3 shader (about 95% accurate, built from shader code) was posted by "jack" in community-upload-download (r93_sniper, 2023-08).
- Subsurface scale can cause a skin/colour glow (soulburnin, 2023-12): reduce Subsurface scale on the Principled BSDF.

## Best leads for these problems
(1) Black or too-dark Reach Elite piece (Honor Guard shoulder). Candidate causes ranked from this slice: (a) metallic/spec intensity too high or no env reflection so tint turns black (gameoverload 2023-04, r93 2022-08); (b) CC mask empty/wrong: control (CC) must hold R=primary, G=secondary, B unused, base albedo must be white, wrong mask makes it "look like hell" (gameoverload 2022-11); (c) mask/control texture set to sRGB instead of Non-Color, or alpha lost during editing (chiefster 2023-09; rennworks 2022-10); (d) the shader/material for that one piece was not the same as working pieces - copy node tree and links from a working piece, or swap the piece's own mask/ASG/normal (exporush 2023-02, chiefster 2023-10, poet 2023-10); (e) zone enable switch off falls back to zone 1 (2023-06); (f) CR4B red nodes or missing detail_map (plastered_crab 2023-07); (g) "pure black/white unreachable" shader floors (pajamas007 2023-03). No Honor-Guard or fresnel-tint specific advice exists in this slice.
(2) Shine/spec wrong on Elite: Material texture channels R spec coefficient, G albedo blend, B env contribution, A roughness; no Material map means spec is in diffuse alpha (Sniper, restated 2022-11/12). Reach/H3 look is dominated by cubemap, which must be equirect-converted (py360convert, Cubemap Converter addon youtu dpMQr59vSys; soulburnin 2023-07, brooen 2023-08). Compare per-material values in Guerilla/Foundation (Reach 1695793) (plastered_crab 2023-10). Reach shaders are close to H3 (r93 2023-08, gameoverload 2023-05); Blender 4.x specular split: Specular Level 0.5, spec colour ~ albedo*0.04 (gameoverload 2023-12). Cubemap alpha role is still unknown (gameoverload 2023-09).
(3) Importing custom armour to Reach: slice has no Reach import tutorial (m0nkeyman117 2023-08). Only leads: export from Blender using the right object (render object, not the sharp-edged body copy) (chiefster 2023-09); rip with Reclaimer to AMF to keep normals; H3 import tutorials exist and Reach is "built off 3" (gameoverload 2023-05); Reach tools were announced later than 2022-08 (hydranaught444). Tag path convention under the EK tags folder (user 2023-07). Material names must be correct for tool-driven shader setup (plastered_crab 2023-03).
(4) Networking of custom armour for other players: not covered. Only adjacent unanswered items: change player colour mid-game, MCC party errors, compiled maps ignoring tag edits, Reach MP-slot map swaps (see Missed facts). Do not infer a network answer from this slice.
