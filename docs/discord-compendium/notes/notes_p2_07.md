## Best leads for these problems
(1) Black or too-dark Reach Elite armour piece (e.g. Honor Guard shoulder)
- First check Blender-style causes: Alpha mode Straight -> Channel Packed on every texture; CC/control maps not wired into base colour; normal map Non-Color; other maps Linear; clear custom split normals; duplicate or overlapping geometry; flipped/mirrored UVs.
- Colour-zone logic: Reach CC maps use R/RG; a piece with missing or wrong channel receives zero tint, which may give black or the unbleached diffuse. In the Blender Reach shader do not replace Diffuse by the primary colour (darkens everything); keep the original diffuse link (x_crimsongalax).
- Spec/fresnel: H3/Reach specular coefficient is a flat multiplier; exponent controls blend between specular colour and fresnel colour; tinted fresnel/spec colour slightly blue brings back brightness (chiefster 2026-06). A zero spec mask or black fresnel colour would read as flat dark (inference).
- No source in these chunks about CC alpha or spec-mask specifically.
(2) Elite shine/specular looking wrong
- Reach/H3 are not PBR: coefficient = spec colour multiplier, exponent = smoothness proxy (gameoverload 2025-05); reflection mask only gates cubemap; H3 uses near-static roughness, visor not super metallic, visor colour x2 brighter; Eevee needs light probes. Elite cubemap shine specifically unanswered; see CE multipurpose reflection setup for method. Check Chief's Reach Elites blend as reference shader.
(3) Importing custom armour to Reach
- Chunk-supported tools: Foundry (Blender addon for Reach, H4, H2A MP; needs MCC from Steam plus Reach mod tools; https://github.com/ILoveAGoodCrisp/Foundry), General-101 toolset for H1-ODST only. For rigging: parent armour to the existing Elite skeleton, name vertex groups to match bones, fix bone axes (X along bone) when porting. Match CC channel layout to Reach's R/RG convention. Nothing here on render_model markers, tag names, or ass/JMS export commands for Reach.
