# Mask-site inventory (static scan of haloreach-copy.dll)

Generated by `python tools/limits/scan_mask_sites.py`. Starting point for the multi-word mask widening in
`TOPIC-scaling-64-128.md` section 3.1: the engine peer-valid/player-valid masks are 32-bit DWORDs, so
capacities above 32 need every mask read/write/bit-scan site widened.

**Heuristic byte scan, not a disassembly.** Hits are candidate AND/TEST/MOV/OR/XOR immediates that are
contiguous low-bit masks (0x7FFF and above) plus the stock 16-bit test r16,r16 form. Every candidate must be
checked by hand before patching.
