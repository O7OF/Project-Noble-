# Project Noble 0.9.16.34

New RR main menu map and remapped Armory GLOBALS: Spartan/Elite armor applies on the new strings.

## Highlights

- **New RR mainmenu_all.map** with its matching elite/spartan armory string table.
- **Armory GLOBALS remapped:** the new map puts head at slot 4, chest at 2 and the flair block at 24-38; armor pairs are resolved by region name instead of assuming the old fixed layout.
- **Spartan and Elite armor** apply through the new layout; the biped rebuilds when a piece changes.
- **4K UI scaling** and **exclusive fullscreen / borderless default** included.
- **Three-region server browser**, native-resolution rendering and crash-only private logs.

## Install

1. Download Project-Noble-v0.9.16.34-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.
