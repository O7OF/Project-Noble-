# Project Noble 0.9.16.35

Armory character restored and armor applications fixed.

## Highlights

- **Armory map restored:** the imported 268 MB menu map does not contain the Spartan Armory scene/camera; its camera range renders a star field. The known-good 297 MB map (which includes the Armory pedestal and character) is back.
- **Armor GLOBALS mapping kept:** region-aware pair writing is retained, and the legacy Armory table applies head/chest/shoulder/wrist/utility/knees/effect pairs.
- **Character visible in the Armory** again.
- **4K UI scaling** and **exclusive fullscreen / borderless default** included.
- **Three-region server browser**, native-resolution rendering and crash-only private logs.

## Install

1. Download Project-Noble-v0.9.16.35-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.

## Notes

- The new imported menu map is preserved as mainmenu.new-import.map for a future pass; using it now removes the Armory character.
- This build supersedes 0.9.16.34.
