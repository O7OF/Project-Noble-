# Project Noble v0.20.31

## Fixes
- **Your flame colour shows for everyone:** Other players now see your armour flames in the colour you picked, in first and third person, instead of the stock colour. Fires in the level keep their normal look.
- **Smoother frame times:** Fixed a small stutter caused by Noble checking your armour settings file far too often.

## Online play
- **Smoother co-op on shaky connections:** In smaller games (up to 8 players) Noble now sends a backup copy of each game update, so one lost update no longer causes a stutter for everyone.
- **Higher upload limits for hosts:** The game's network limits from 2010 have been raised, so hosts with faster internet can send more updates to their players. Fast connections and dedicated servers are no longer held to a 10 Mbit/s limit.
- **Closest server picked automatically:** When you host, Noble picks the server closest to you by itself. Campaign games with high ping show a warning before you join.

## Firefight
- **Up to 16 players** in a Firefight lobby.

## Interface
- **Connection info:** A new NETWORK STATS option in Settings shows your ping, packet loss and network use. The scoreboard marks players with a poor connection, and loading screens now show tips.

## Stability
- **Game version check:** Noble checks that your Halo: Reach files are the version it was made for, so an MCC update can be spotted and handled safely.
