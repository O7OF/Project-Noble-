# Project Noble Release Notes --- v0.20.17

### 3rd-Person Dynamic Reticle Smoothing & Intuitive Armory Controls
- **[GAMEPLAY] 3rd-Person Dynamic Reticle Smoothing:** Added screen-space dynamic interpolation to the third-person reticle, eliminating character animation jitter and geometry snapping so the crosshair glides smoothly across the screen while moving.
- **[ARMORY] Intuitive Armory Controller Navigation:** Enhanced controller flow across customization menus: pressing Right or A seamlessly enters the options grid, Left on the edge returns to the slot list, and X provides an instant purchase shortcut with zero trap states.
- **[CONTROLS] Seamless Navigation Parity:** Refined D-pad and analog stick navigation boundaries across armor customization grids and slot categories with silky smooth cursor transitions.
