# Project Noble v0.19.66 (Closed Source)

### Pure UPnP P2P Networking & Non-Host Input Latency Elimination
- **Pure P2P Direct UDP Priority:** Fixed an issue where the host evaluated direct UDP based solely on ping/pong probes, causing port 1000 simulation traffic to fall back to the WebSocket relay queue and introducing heavy input latency and desync for non-host clients. Simulation packets now flow exclusively through direct UDP datagrams when direct UDP is active (`route.directConfirmed` or recent UDP traffic received within 3000 ms).
- **Instant Bidirectional UDP Latching:** Both host and guest immediately latch `directConfirmed = true` upon receiving ANY valid direct UDP packet (including NAT punch PING/PONG and in-game wire packets), immediately activating 0-latency direct transmission.
- **Robust Multi-Burst NAT Hole-Punching:** Guest initial NAT hole punch now transmits a 5-packet burst across WAN, LAN, and localhost endpoints to immediately open NAT router firewalls and bypass Hairpin NAT limitations. Host answers with a 3-packet PONG burst + PING probe for rapid 1-RTT synchronization.

### Rapid Disconnect & Anti-Ghost Server Fixes
- **Dedicated `"DISC"` Wire Datagram:** Implemented `NetworkTransport::SendDisconnectPacket()` which broadcasts a burst of `"DISC"` datagrams on port 1001 and sends `lobby_leave` over the relay socket. Remote hosts and guests immediately remove the disconnecting peer from `m_peerTable`, `m_gamePeers`, and route states with zero lingering or hang.
- **Synchronous Master Session Unregistration:** `StopAdvertisingSync()` replaces asynchronous deletion across menus and server browser stops, preventing ghost or empty sessions from reappearing when returning to the server browser.
- **Master Server Timeout & Auto-Disband Streamlining:** Master session timeout reduced from 90 s to 15 s. Host disconnect grace timer reduced to 2 seconds on WebSocket closure, and disconnected guests are immediately pruned from the room roster and player count.
- **Server Browser Region Badge & Federation Priority:** Fixed cross-region session discovery where federated copies could overwrite native home region URLs. Added colored badges for US East, US West, UK, LAN, and YOU directly in the server list and detail inspection panes.
