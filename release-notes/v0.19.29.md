# Project Noble v0.19.29 Release Notes

### Developer Cheat Menu Engine Fixes & Dev Build Isolation
- **Developer Build Exclusivity (`NOBLE_DEV_BUILD`):** Completely compiled out the developer mod & cheat menu, its keybindings, overlay render callbacks, and underlying cheat hooks from release builds (`noble-client.exe`). All developer functionality is strictly isolated to development binaries (`noble-dev.exe`).
- **Engine Game Thread Execution:** Relocated cheat simulation logic to `user_control_tick` (RVA `0x61A38`) on the engine's game thread via `SpawnTest` integration, ensuring TLS slot access (`0xC17B18`), `player_mapping_get_unit_by_output_user` (RVA `0x53EF8`), and `object_get_ultimate_parent` (RVA `0x473DC0`) resolve valid pointers on every simulation tick.
- **Cheats Operational Verification:**
  - **Godmode:** Real-time damage blocking (`0x1ED320`), death blocking (`0x47CAA8`), and instant shield restoration (`0x49DD58`) with direct health component verification (`biped + 0x186`).
  - **Super Jump & Super Speed:** Active velocity scaling on biped impulses (`+0x68`).
  - **Noclip (Ghost Flight):** 6-DOF collision bypass with WASD movement, Space ascension, and Ctrl descension.
  - **Infinite Ammo & Bottomless Clip:** Carried weapon magazine (`+0x3030`) and reserve (`+0x3034`) replenishment along with plasma weapon battery/heat resets.
- **Native Object Spawning & Give System:**
  - Integrated native `object_placement_data_new` (RVA `0x49CC24`) and `object_new` (RVA `0x46D6E0`) for universal item placement across all gamemodes (Campaign, Firefight, Forge, Custom Games, Multiplayer).
  - Added direct item equipping via `unit_inventory_add_weapon` (RVA `0x48F778`) with dedicated **[ GIVE ]** buttons for instant in-hand weapon and equipment delivery.
  - Implemented dynamic active map tag discovery from `tagTable` (`0xC1A600`) and the live object pool to allow spawning and giving any loaded weapon, vehicle, or equipment entity in the active match.
