# Project Noble Release Notes --- v0.19.90

## Theater Mode Saved Film Playback Fix
- Fixed Theater Mode saved film playback where selecting clips previously caused `mainmenu.map` (the background space cruiser image) to load instead of the actual match film.
- **Accurate Scenario & Map ID Extraction:** `flmh` headers are now inspected directly at `flmh + 0x5EC` (`0x92C`) with automatic scanning fallbacks across `flmh` and graceful mapping via `ScenarioFromReachMapId`.
- **Mode-Aware Film Resolution:** Saved films automatically configure Campaign (`chdrMode == 3`), Firefight (`chdrMode == 4`), Forge, or Multiplayer engine classes and launch block descriptors.
- **Automatic MCC Film Sync:** `SyncAutosaveFilmsToTheater()` now automatically detects and syncs local MCC autosaves (`AppData\LocalLow\MCC\Temporary\HaloReach\autosave`) directly into the Theater menu.
- **Sandbox Staging & Direct Launch:** Saved film files are safely staged to `sandbox\theater\` and `sandbox\` with non-null pointer injection into `launch_block + 0x2BF20`, activating `haloreach.dll`'s `c_saved_film_director`.
