# v0.19.53

## Diagnostics for the co-op failure, and readable release logs

The campaign co-op session still ends a few seconds after both players spawn, and the last pass narrowed it one step
further: the host no longer boots the guest (that fix holds), but the **guest's own engine finishes the mission**
(its game-finish path `hr+0x355F1` -> `hr+0x59330`), the guest leaves the session, and the host disbands.

To pin down what ends the guest's simulation, this build:

- logs who requests a session teardown, with the engine RVA for messages 12 (leave), 14 (disband) and 15 (boot);
- keeps module-relative RVAs in release logs. They are identical in every copy of the game and were the one thing
  missing from the reports; absolute 64-bit addresses and IPs are still redacted.

The campaign keep-peer change from v0.19.52 is unchanged.
