# Project Noble v0.19.73 Release Notes

## Summary
- **Post-Game Credit & Stat Saving for All Clients:** Fixed issue where non-host clients did not receive credits or save career progression after match completion. Added networked `match_over` packet broadcast from host to all connected peers, robust local player datum resolution in `Career::LocalPlayer` (matching local player name and engine TLS local machine bit `0x08`), and guaranteed fallback persistence in `EnsureMatchSaved`.
- **Return to Menu & Relaunch Crash Fix:** Fixed crash when clicking `RETURN TO MENU` from the post-game results screen. Corrected command-line argument propagation (`-main-menu`), properly routed container relaunch back to `Screen::Main`, and eliminated blocking 30-second sleep in `Relaunch::HandOff` to prevent thread hangs during engine shutdown.
- **Enhanced Post-Game Results Flow:** Non-host clients no longer get abruptly disconnected or kicked out when matches end or when the host returns to the lobby; guests can now view full post-game stats, awards, commendations, and credits, with an interactive `RETURN TO LOBBY` button and a graceful auto-countdown.
- **Match Start & End Load Optimization:** Optimized engine simulation settling delay from 3000ms down to 400-1000ms upon player join confirmation, significantly accelerating match launch and transitions.
