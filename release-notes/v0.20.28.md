# Project Noble v0.20.28

## Master Server & Match Discovery Fix
- **0.20.x Master Server Registration:** Updated backend master server protocol validation in `ServerTestDeploy/server.js` and client handshake in `MasterServerClient.cpp` to natively accept `0.20.x` builds. This resolves the `403 client_outdated` rejection that previously caused hosted sessions to fail registration and prevented active matches from appearing in the live Server Browser.
- **Session Visibility & Query Compatibility:** Updated `sessionVisible` and `isCompatibleBuild` to ensure `0.20.x` hosted sessions are cataloged, refreshed, and broadcast to all querying clients on both release and dev branches.
- **Client Synchronization:** Ensured Server Browser telemetry, ping monitoring, and match listing reflect all live lobbies accurately across all modes (Campaign, Multiplayer, Firefight, and Forge).
