# Project Noble 0.19.21 (Closed Source)

## What's New in v0.19.21

### Auto-Update & Antivirus False-Positive Hardening
- **Direct Azure Blob Storage Download:** Switched release asset resolution to use the release asset API endpoint (`Accept: application/octet-stream`), bypassing `github.com` HTTP 504 gateway timeouts and downloading directly from Azure Blob storage.
- **WinHTTP Redirect & Timeout Resiliency:** Configured WinHTTP with automatic cross-domain redirect policies (`WINHTTP_OPTION_REDIRECT_POLICY_ALWAYS`), fallback location traversal, and extended connection timeouts.
- **Replaced PowerShell Script with Clean Native Batch:** Replaced `apply_update.ps1` and hidden `powershell.exe -ExecutionPolicy Bypass` with a lightweight, clean `apply_update.cmd` script utilizing standard Windows utilities (`tasklist`, `tar.exe`, `robocopy`). This completely eliminates AMSI script warnings and resolves Windows Defender heuristic false positives (`Trojan:Win32/Bearfoos.A!ml`).
- **Standard Windows PE Version Information:** Embedded a complete `VS_VERSION_INFO` resource table into `noble-client.exe` containing company name, product title, file descriptions, legal copyright, and version numbering (`0.19.21.0`), preventing machine-learning heuristics from penalizing anonymous executables.

## Install

Use the in-game **UPDATE AVAILABLE** banner on the main menu to update automatically, or unzip `Project-Noble-v0.19.21-win64.zip` over your existing installation. Your settings, career progress, and custom appearances are saved locally in `data\userdata` and are never overwritten.
