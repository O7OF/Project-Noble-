# Project Noble Release Notes — v0.19.97

### Stability

- **Fixed the 0.19.96 null-slot guard trampoline.** Both relative jumps in the guard were five bytes short, so a guarded call could resume in the middle of an instruction (illegal instruction at `haloreach+0x41E40D`). The offsets now point at `0x41E3EB` (slot non-null) and `0x41E410` (slot null) exactly. A two-instance test reproduced the fault on 0.19.96 and runs clean on 0.19.97.

### Netplay verification (host + guest on one PC, `-local-port`)

- Host and guest completed the NAT punch, join handshake and membership wait on 20_sword_slayer; the guest rendered in-game (screenshot bright).
- Host quit mid-match: the guest reported the connection loss, received the session-disband, ended the game normally (reason 2), showed the post-game panel and exited with **no crash dump**. This is the non-host match-end path that used to crash.

### Version

- 0.19.96 → **0.19.97** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
