# Project Noble v0.19.72 Release Notes

## Summary
- **Forge World & Large Map Stability:** Fixed `0xC0000005` crash at `haloreach+0x2C2E0B` when loading Forge World (`forge_halo.map`) and other large maps. Guarded object array expansion (`object = 32767`) behind offline bank expansion patches (`s_hasOfflinePatches`), preventing Bank 4 (stock 4.78 MB limit) game-state memory overflow.
- **Authentic Loading Screen Progress Bar:** Replaced the marquee bouncing animation with an authentic, real-time loading progress bar showing exact percentages (`0%` - `100%`) sampled directly from the Blam! engine loading progress memory (`haloreach.dll+0x46F0E04`).
- **Engine Interface Synchronization:** Fixed `HostSlot23_LoadProgress` handling in `ReachHost` to accurately query and propagate live engine load fractions to the UI and 3D wireframe renderers.
