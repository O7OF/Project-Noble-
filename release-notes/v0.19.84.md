# Project Noble Release Notes — v0.19.84

### Audio: gain staging fixed (game audio full quality)

- **Game audio is no longer scaled twice.** Noble used to set this process's WASAPI session volume to GAME while also passing GAME/MUSIC/OTHER to the engine. With stock 0.50 levels that made music, dialogue and other players 0.25, and the whole mix dropped another 6 dB whenever GAME was lowered. The session-wide gain stage is gone; the engine mixer is the only gain stage.
- **MASTER MUTE is menu-only again**, matching its setting description. It no longer silences the game, and a mute/zero at launch can no longer leave the running mixer permanently silent.
- **MUSIC and OTHER now work during a match.** `ReachHost::SetRuntimeVolumes` writes the live mixer floats in `haloreach.dll` (game/music/other) as well as the profile fields, so mid-match changes are audible instead of only applying on the next load.
- **Background mute still works:** `muteInBackground` zeroes the game mix while the window is not foreground and restores it on focus.

Game audio was never compressed by Noble: the engine's own mix is passed through. Voice chat remains Opus (mono); it is unrelated to the game mix.
