# v0.19.54

## Two-player campaign co-op works; tracing the three-player end

With this series of fixes a two-player campaign co-op session now plays, which is the first time co-op has held past
the spawn. With a third player the mission runs for a short while and then the engine ends it with the same co-op
error.

The engine ends a match when its "game running" flag (TLS block +0x48, byte +0x1EAB8) goes to zero. That flag is now
logged every time it changes, with the frame number, so the next three-player report shows the exact moment the
mission is declared over and which peer event precedes it.

Nothing else changed in this build.
