# Project Noble v0.20.25

## Custom Flame Colors (Armory & Multiplayer P2P Replication)
- **Armory Persistent Flame Preview:** Fixed an issue where custom primary flame variants (30 authentic Halo: Reach armor colors + auto primary match) would immediately de-load in the 3D Armory preview. Mapped all primary flame variants to native `legendary_flame` and permutation `armor_fx_00`, which exist in all maps including `noble_menu.map`, and updated `ParticleTint` to immediately switch the runtime particle palette texture so flames remain continuously attached and rendered without resetting.
- **P2P Multiplayer Replication:** Implemented full network synchronization for custom primary flame variants matching the custom visor and armor lights architecture. Stamped appearance records (`rec[0x1A]`) and player settings sync blocks (`block32[8]`) with the flame variant bitmask (`0x80 | (flameVariant & 0x1F)`). Both host and non-host clients now accurately resolve and render custom flame colors for all players across multiplayer matches.

## In-Game Mouse Cursor & Native UI Navigation
- **Loadout & In-Game UI Cursor:** Ensured the mouse cursor reliably displays during active in-game native UI screens (such as loadout selection, Forge palette, pause screen, and game-over screens).
- **Themed Reticle & OS Cursor:** The styled circular reticle cursor is rendered smoothly at `io.MousePos` when `mouseReticleCursor` is enabled, and standard Windows `IDC_ARROW` is restored when disabled, ensuring seamless and glitch-free mouse interaction across all modes.
