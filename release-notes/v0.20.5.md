# Project Noble Release Notes --- v0.20.5

### Joining a game in progress (Firefight)
- The host used to refuse a joining player's session with refusal reason 3 (join in progress) even after the join gates were patched, which sent the client back to the main menu. When Noble is hosting an active session, that refusal is now dropped so the engine's own join handshake can complete. Refusals for other reasons (full, wrong version, banned) still go through.

### Multiplayer visibility (from v0.20.4)
- Guests see the full lobby roster and player count on the loading screen.
- Only the local player is marked "YOU" on the scoreboard, with correct per-player service tags.
- Ping is resolved per player for joining clients.
- Invite joins connect directly to the host and show the host's real player name, not the lobby name.
- The server browser shows the same version as the main menu.

### Performance
- AMD CPU frame rate: process power throttling disabled, above-normal process priority, the render thread raised to above normal, and the system kept awake.

### Known remaining work
- Settings save reliability when the menu process and the match process both write (needs a merge-on-save pass).
- Firefight mods over the network.
