# Project Noble Release Notes - v0.19.99

### All-Mode Stability & Engine Fixes

- **Fixed LTCG volatile register clobber crashes:** Wrapped `Hook_GameFinish` (`haloreach.dll+0x355F1` / `0x59330`), `Hook_IsWhitespace` (`0x362E8`), and `HookGetVariantSource` (`0x6BCEC`) in register-preserving x64 stubs (`rflags`, `rax`/`rcx`/`rdx`/`r8..r11`, and `xmm0..xmm5`), resolving mid-match/finish crash dumps and preserving caller register state.
- **Includes 0.19.95-0.19.98 fixes:** Campaign intro cutscenes no longer black-screen, `m05` / `m70_bonus` finish cleanly, UI null-slot crash guard trampoline at `0x41E3E3` is fixed, third-person camera tuning runs once per frame, and `NOBLE_MACHINE_ID` parsing preserves real scoreboard ping identity.

### Networking, Handshake & Sync Guards

- **Bidirectional UDP route verification (`pongConfirmed`):** Direct UDP transport no longer treats outbound/one-way packets (`NVOX`/`NBCJ`/game frames) as confirmed two-way paths; routes require an explicit recent `PONG` within 3.5 s, eliminating asymmetric packet drops and JIP disconnections.
- **Blam! membership launch handshake & abort checks:** Host waits for connecting guests to complete Blam! membership (`playersJoined`) with a timed fallback, settles cleanly, and aborts cleanly if the match shuts down mid-join.
- **All-mode variant & `.mvar` map variant sync with SHA-256 verification:** Host preset JSON and binary `.bin` game variants (`Custom Games`, `Firefight`, `Forge`) and `.mvar` Forge map variants are transferred and SHA-256 verified over both WebSocket control messages and HTTP `/api/sessions/:id/lobby?assets=1` before guest launch, alongside Co-op support across Campaign and Firefight.
- **Master Server (`ServerTestDeploy`) guards:** Enforced `role === 'host'` on host-only WebSocket events (`lobby_launch`, `host_return_to_lobby`, `lobby_disband`), cleared stale `isMod`/`mod_id`/`mod_title` on heartbeat & stock map selection, and improved `/lobby/leave` cleanup.

### Smooth In-App Steam Workshop Downloader

- **In-app SteamUGC + direct CDN downloader:** Clicking download on a missing Workshop mod now subscribes and downloads in the background without popping open Steam, reporting real byte progress (`downloaded / total`, `MB/s` speed, ETA, and stage) into a determinate progress bar.
- **Full Workshop briefing:** Displays mod title, creator persona name & SteamID, file size, updated date, subscribers/favorites, dependency count, tags, thumbnail preview, and BBCode-cleaned description in a controller-friendly scrollable panel.
