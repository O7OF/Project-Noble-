# Project Noble v0.19.38 Release Notes

## Firefight Fixes
- **Beachhead Map Loading Fix.** Fixed an inverted map ID resolution bug in `BlamEngine.cpp` where Beachhead (`ff50_park`) was swapped with Overlook (`ff10_prototype`). Selecting Beachhead in Firefight now reliably loads Beachhead (`launch index 210`) rather than Overlook (`launch index 216`).

## Full-Screen Loading Screen Art & Clean Layout
- **Authentic Per-Map Backgrounds.** Every map now uses its own authentic image as its full-screen loading background:
  - Campaign missions display their 1080p mission scene artwork.
  - Firefight, Multiplayer, and Forge maps display their authentic high-resolution preview art loaded directly from `levelstexturepack` (`REACHFIREFIGHT_BEACHHEADLARGE`, `HREACHMP_FORGEWORLDLARGE`, etc.).
  - Custom Workshop/mod maps display their custom artwork (`-map-image` or mod folder picture).
  - The legacy random campaign scene fallback for non-campaign maps has been removed.
- **Clean, Clutter-Free Presentation.** Removed the awkward floating thumbnail preview box in the lower-right corner. The map's background art now fills the entire screen with a smooth dark gradient across the bottom half to ensure crisp contrast. "LOADING", the map title, and the animated accent progress bar are neatly aligned with no overlapping boxes or misaligned text.
- **Immediate Map Info Registration.** Wired `PauseMenu::SetLoadingMap` and `SetLoadingMapInfo` into `main.cpp` and `BlamEngine::LaunchGame` at process start, ensuring map titles and artwork are available on frame 1 without delay.

## Single-Window Container Launcher: Presentation & Flickering Fixes
- **Parent Presentation Silenced During Matches.** Fixed violent 30–60 Hz flickering where the Armory background (`UiArt::MenuBackground()` Covenant glassing cruiser artwork) overlayed cutscenes and gameplay during a match. In container mode, the launcher process now flags `IsMatchRunning(true)` and completely discards parent swapchain presentations (`return S_OK`) and engine ticks (`HostSlot1_FrameTick` returns 0).
- **Parent Message Loop Idling & Match Status Tracking.** While a match runs in the embedded child window, the launcher bypasses `blamEngine->Update` and `HoldFrame`, polling child process lifetime via `FrontEndMenu::CheckMatchStatus()`. When the match finishes, the launcher automatically closes process handles, restores audio and networking, and seamlessly brings back the main menu in the same window.
- **Window Z-Ordering & Clipping.** The container parent window now enforces `WS_CLIPCHILDREN | WS_CLIPSIBLINGS`, and the child match window is positioned at `HWND_TOP` with `WS_EX_NOPARENTNOTIFY`, preventing DWM presentation overlap.

## Build System
- Dedicated server build bypassed: builds and release packaging strictly target `noble-client`.
- Version bumped to **0.19.38** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
