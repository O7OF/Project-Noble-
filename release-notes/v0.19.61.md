# v0.19.61

## Map variants under their base maps, and a named Forge save

* The maps menu (Custom Game and Forge) now nests each base map's Forge variants beneath it: MCC's own
  `haloreach\map_variants` and `haloreach\hopper_map_variants` (266 files) are listed next to `data\map_variants`,
  so every base variant is playable and a large, known-good set exists to test loading against.
* The Forge pause menu has **SAVE MAP VARIANT**, which asks for a name in a text box, writes the variant into
  `data\map_variants\<name>.mvar` and stores that name as the variant's title (+0xC0, UTF-16), so it appears under
  its base map with the name you typed.

Verified: variants list and launch from under their base maps (screenshot in the log thread).

Known open: the engine's own `save_map`/`save_map_as` creates its autosave temp file
(`saves\HaloReach\autosave\asq_mglo--1_...temp`) but writes zero bytes, so the save button currently reports that
no file was produced. The engine's map-variant writer - not the UI - is what still needs to be made to complete.
