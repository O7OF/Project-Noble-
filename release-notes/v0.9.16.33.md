# Project Noble 0.9.16.33

Armor application fix, plus the latest 4K UI scaling and display modes from 0.9.16.32.

## Highlights

- **Armor applies correctly again.** The Armory uses the map/string table its permutation data was built against; item names resolve to the real model regions and rebuild the biped.
- **Helmets, helmets attachments, shoulders, chest, wrists, utility, knees and effects** apply through the same translation path.
- **4K UI scaling** from 0.9.16.32.
- **Exclusive fullscreen / borderless default** from 0.9.16.31.
- **Crash-only private release log**, no release diagnostic dumps.
- **Three-region server browser** and native-resolution rendering.

## Install

1. Download Project-Noble-v0.9.16.33-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.

- This build supersedes 0.9.16.30.
