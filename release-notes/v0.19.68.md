# Project Noble v0.19.68 (Closed Source)

## Performance & AMD Ryzen/Radeon Compatibility Fixes
- **Resolved 47 FPS Throttling & Focus Desync:**
  - Expanded `Window::IsForeground` to evaluate window hierarchy across root ancestor trees (`GA_ROOT`), parent/child relationships, and process IDs for both the match container child and the host launcher window.
  - Added a 1.5-second debounce window to `HookSwapChainPresent`'s background frame throttling (`throttleUnfocused`). Transient focus handoffs, mouse clipping, and Win32 focus transitions no longer trigger spurious drops to 30 FPS.
  - Eliminated repetitive focus thrashing by only invoking `Window::RequestFocus()` when focus is actually lost.
- **Microsecond Frame Pacing Precision:**
  - Adjusted the high-resolution frame pacer to only invoke `Sleep()` when more than 2.0 ms remains before the frame target deadline.
  - Handed the final sub-2ms slice to `YieldProcessor()` (`_mm_pause`) for exact microsecond precision without overshooting the frame presentation time.

## Stability & Crash Fixes
- **Fixed Fatal Crash at `haloreach.dll+0x99A0D` (0xC0000005 NULL Biped Dereference):**
  - Resolved access violation crash during Campaign autosaves (`asq_campaign_m10`), checkpoints, and cutscenes caused by the engine iterating player datums without verifying that the corresponding biped datum pointer is non-null.
  - Installed a near-trampoline patch at `haloreach.dll+0x99A0D` that safely routes null bipeds to the engine's clean detachment path (`0x99A39`), preventing fatal crashes.
