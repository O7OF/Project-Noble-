# Project Noble Release Notes --- v0.19.103

This build collects the work that landed after v0.19.102: shareable lobby codes, the map-variant drawer filters,
server-browser and menu click fixes, and the toggle crouch / toggle zoom bindings.

### Lobby share codes

- **Hosts of public and private lobbies can share a join code** instead of an address. The pre-game lobby HOSTING
  panel shows the code with a **COPY CODE** button.
- Codes look like **`NB1-XXXX-XXXX-XXXX-XXXX`** (23 characters) and encode the session, not an IP address. Private
  lobbies stay unlisted, but the same code still joins them.
- Join a code from the **Main Menu > JOIN WITH CODE**, the **Server Browser > JOIN WITH CODE** button, or the
  **Social** screen's prominent **JOIN WITH CODE** button.

### Map pickers

- **The expanded base-map / variant drawer now has a search box and a category filter.** Type part of a variant name
  (for example "jump"), or cycle categories (ALL MODES, Forge, Slayer, Capture the Flag, etc.); the drawer shows
  `N OF M VARIANTS` and keeps the section collapsed/folded state working as before.
- Forge World AI Battlegrounds (353 variants) filters down to the matching entries instead of forcing a long scroll.

### Server browser

- **Refresh shows its status again** while the list is reloading.
- **FAVOURITE and COPY INVITE are pinned in a fixed footer** under the details pane, so they stay visible and
  clickable without scrolling the server details.

### Menus and settings

- **Game Options rows are clickable anywhere on the row**, and the main-menu "N What's New" hint is clickable again.
- **Controller: toggle crouch** is available in Settings > Controls.
- **Mouse & keyboard: toggle zoom** is available in Settings > Controls.

### Visors

- Unchanged from v0.19.102: every Armory finish writes a valid stock engine visor slot, so nothing renders white, and
  the five stock colours are exact in game. Extended finishes such as Blood Orange remain exact in the Armory preview
  and use the nearest stock colour in matches; exact per-player custom visor colours are still a separate engine task.

### Also

- The optional Forge World pack ships as a separate asset (`Noble-ForgeWorld-v0.19.103-win64.zip`); base and Forge
  pack versions must match.
- Campaign co-op / Firefight co-op launch blocks still declare at most 16 players. Larger player counts are tracked
  as a separate project.
