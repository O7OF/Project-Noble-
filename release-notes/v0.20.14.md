# Project Noble Release Notes --- v0.20.14

### Extended 32-Player Lobbies, High-Capacity Netcode & Browser Filters
- **[MULTIPLAYER] Extended 32-Player Matches:** Custom Games and Forge lobbies now support expanded matches up to 32 players with full roster and scoreboard tracking.
- **[NETCODE] High-Capacity Discovery & Sync:** Upgraded network beacon and server browser discovery to seamlessly discover, list, and sync high-capacity lobbies up to 32 players without truncation.
- **[SERVER BROWSER] Dynamic Capacity Filters:** Updated the Server Browser to accurately reflect live server capacity, allowing players to filter and join expanded community lobbies without capacity restriction warnings.
- **[LOBBY] Max Players Picker:** Host lobby settings now allow directly selecting up to 32 players for Custom Games and Forge sessions.
- **[UI] Loading Screen Multi-Column Roster:** Enhanced in-match loading screens with responsive multi-column roster formatting to cleanly present all players in expanded matches.
