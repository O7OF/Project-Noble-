# Project Noble v0.20.27

## Engine Crash Mitigations (Crash Dump Fixes)
- **Near-Trampoline 64-Bit Hook Allocation:** Replaced linear unaligned `VirtualAlloc` loops with a robust 64KB-aligned `VirtualQuery` scanner in `EnginePatches.cpp`, guaranteeing all 64-bit near-trampolines land within the 2GB relative branch range of `haloreach.dll`. This resolves retail unpatched crashes at `haloreach.dll+0x41E3EB` where detours previously failed to allocate on 64-bit systems.
- **Tag Datum Resolution Guard (0x92850):** Added `Hook_TagResolve` at `haloreach.dll+0x92844` to intercept null tag datum pointers (`rdx == NULL`). Safely initializes output datum headers to 0 and returns immediately, eliminating null-pointer crashes during dynamic effect and tag queries.
- **Unit Iteration Bounds Check (0x1650A1):** Added near-trampoline guard at `haloreach.dll+0x16509C` that checks for null unit pointers (`test r8, r8; jz 0x16523B`), gracefully skipping non-existent bipeds and preventing dereference crashes during active gameplay and match startup.

## Join-in-Progress & Peer De-Duplication
- **Universal Join-in-Progress Unblocking:** In `LobbyPatches.cpp`, suppressed engine refusal reason 3 (session locked / join-in-progress locked) across Campaign, Firefight, Custom Games, and Forge whenever network transport is active, allowing players to join live matches seamlessly.
- **Peer Bitmask Tracking & Phantom Bot Removal:** Replaced packet-count heuristics with unique peer bitmasks (`s_remotePeerMask`) in message decoding and remote player tracking. Prevents packet retransmissions from artificially inflating the join count (which previously generated dozens of phantom "PLAYER X" bot rows and triggered premature simulation start after 20 seconds while real players were still loading).

## Campaign Co-Op & Firefight Expansion
- **Campaign 4+ Player Support:** Removed the 4-player cap in Campaign co-op launch block allocation (`0xE8`), dynamically declaring up to 16 player slots for all connected and expected peers.
- **Roster & Loading Screen Honesty:** Loading and waiting screens now strictly reflect real expected players and active peers, ensuring clean status indicators for all players in Campaign, Firefight, Custom Games, and Forge.

## Server Browser & Cross-Build Lobby Compatibility
- **Client Version Badge:** Prominently displays the current client version (`CLIENT: 0.20.27` or `0.20.27-dev`) directly in the Server Browser header alongside NAT status and live telemetry.
- **Exact Numeric Matching with Dev Compatibility:** Version checking enforces exact base version parity (`0.20.27`), blocking outdated clients from joining, while allowing release and dev builds with matching numeric versions (`0.20.27` <-> `0.20.27-dev`) to host and join each other's sessions without restriction.
