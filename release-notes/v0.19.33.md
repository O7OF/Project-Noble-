# Project Noble v0.19.33 Release Notes

## UI & Visual Modernization
- **Modernized Scoreboard:** Completely overhauled the in-match scoreboard to replicate the 2-column layout from the reference design:
  - Red Team and Blue Team 2-column split with placement numbers, aggregate team scores, and team K/D/A totals.
  - Subheaders: `PLAYERS`, `SCORE`, `K`, `D`, `A`, `PING`.
  - Player rows display placement rank, emblem badge, red-cross mute badge for muted players, bold gamertag with service tag subtitle, rank insignia icons, scores, kills, deaths, assists, and color-coded ping pills.
  - Bottom bar with controller prompts: `[A] Player options`, `[Scroll] Scroll`, `[Tab] Close`, match watermark, and mini score indicator pills.
  - Interactive Player Options popup allowing individual player muting and "Mute All Players" toggles.
- **Configured Ping Thresholds:**
  - Green: 0 - 100 ms
  - Yellow: 100 - 150 ms
  - Red: 150 - 200+ ms
- **Audio & SFX Improvements:**
  - Set default master menu music, game sound, and other audio volumes to 50% (0.50f).
  - Added debouncing timers (60-80ms cooldown) to `MenuSounds` (`Click`, `Back`, `Scroll`, `Change`, `Tab`, `Error`, `Hover`) to prevent double-triggering or audio flanging across clicks and gamepad inputs.
- **Forge Menu UI:**
  - Enabled mouse scrollwheel scrolling through custom object lists.
  - Added full controller analog stick (LStick/RStick) and D-pad navigation with auto-scroll-to-view.
  - Added bumper button (LB/RB) category switching.
- **Forge Game Mode Options:**
  - Removed "Coming later" placeholder on the Forge setup menu.
  - Enabled full Game Mode Options editing and saving for Forge matches, matching Custom Games capabilities.
- **Server Browser Polish:**
  - Full controller support (analog sticks, D-pad, bumper tabs, triggers, A to join, B to back, X to refresh, Y to favorite).
  - Modern bottom hints bar and clean padding.
