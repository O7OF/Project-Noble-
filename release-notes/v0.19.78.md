# Project Noble Release Notes — v0.19.78

### Matchmaking, Lobby Joining & Server Browser Fixes

- **Pre-Game Lobby Invite Join Handshake:**
  - Resolved an issue where clicking "JOIN" on an invite or toast notification bypassed the pre-game lobby and attempted to launch into an active match prematurely.
  - Joining an invite (from the Social menu, Friends list, or on-screen Toast popup) now directly invokes `EnterLobby()`, cleanly connecting the guest to the host's relay session, synchronizing the lobby roster in real time, and placing the player into the Pre-Game Lobby alongside the host.
  - Matches transition synchronously when the host presses "START GAME", broadcasting map, game mode, custom variants, difficulty, and mod details to all joined lobby members.

- **Fixed Server Browser Session Registration:**
  - Fixed a critical issue in `MasterServerClient` where hosts generated a session ID on advertisement but skipped the `POST /api/sessions` registration request because `existingId` was populated without a validated token.
  - `MasterServerClient::WorkerLoop()` now validates both session ID and session token before marking a session registered. The host properly executes `POST /api/sessions` on the master server (`https://projectnoblebackend.onrender.com`), creating the session in the cluster registry and establishing the WebSocket relay channel immediately.
  - Re-heartbeat requests automatically fall back to re-registration if the master server returns 404 or 403, preventing ghost or unadvertised host sessions.
  - Master server client URL now strictly defaults to `https://projectnoblebackend.onrender.com` so requests are never dropped due to uninitialized URLs.

- **Universal Build & Tag Cross-Compatibility:**
  - Updated `AreBuildsCompatible()` in the client and `isCompatibleBuild()` / `sessionVisible()` on the backend so all players running any 0.19.x build (Normal, Tester, Dev tags) can discover, host, and join games together seamlessly.
  - Backend `/api/browser` and `/api/sessions` endpoints no longer filter out newly created sessions with zero players, guaranteeing host listings appear immediately on the server browser for everyone.
