# Project Noble 0.19.24 (Closed Source)

## What's New in v0.19.24

### Native Base-Game Forge Spawning & Complete Palette Replica
- **Zero Mod Dependency for AI Spawning:** Campaign AI bipeds (Spartans, ODSTs, Troopers, Grunts, Jackals, Skirmishers, Elites, Hunters, Drones) and custom vehicles are now sourced directly from local MCC installation maps (`m20.map` / Sword Base). Players no longer need to download or install external Steam Workshop mods to spawn AI in Forge.
- **Direct Object Creation Pipeline (`object_create_from_params`):** Replaced the restrictive UI monitor check with a direct simulation object creation pipeline (RVA `0x7311B8`). When placing objects from the custom menu, the item is instantiated in the world 3.5m in front of the local player/monitor, with real-time UI status updates (`"Object placed successfully!"` / `"Object placement failed."`) to prevent infinite pending state.
- **Complete Native Forge Palette Replica:** Replaced the partial mod menu with a complete replica of Halo: Reach's actual Forge menu containing all standard categories: **SPAWNS**, **GOALS**, **WEAPONS**, **VEHICLES**, **EQUIPMENT**, **SCENERY**, **BUILDING BLOCKS**, **GADGETS**, **LIGHTS**, **NATURAL**, plus custom **UNSC INFANTRY**, **COVENANT INFANTRY**, and **SPECIAL & BOSSES**.
- **Flyable Base Pelican (`wraith_d` driver seat):** Removed obsolete mod tags (`phantom_mp` and `pelican_o7`). Added the authentic base Pelican tag (`objects\vehicles\human\pelican\pelican`) and dynamically patched its driver seat label in RAM from `pelican_d` to `wraith_d`, allowing players to enter the cockpit and fly the dropship directly.

## Install

Use the in-game **UPDATE AVAILABLE** banner on the main menu to update automatically, or unzip `Project-Noble-v0.19.24-win64.zip` over your existing installation. Your settings, career progress, and custom appearances are saved locally in `data\userdata` and are never overwritten.
