# Project Noble v0.19.25 Release Notes

## Native Forge Palette Injection & Custom Menu Spawning Engine

### 1. Dual Engine Abort Hooks (Unrestricted Object Spawning)
- **Edit-Mode Check Bypass (RVA `0x692CA5`):** In retail `haloreach.dll`, the engine tests `cmp byte ptr [rax+1], 0` and jumps directly to function exit (`0F 84 9A 00 00 00: jz +0x9A`) if the player is not actively grabbing an object in Monitor edit mode. NOPed this 6-byte jump (`90 90 90 90 90 90`), allowing objects to be placed dynamically anytime from custom menus or hotkeys.
- **AI Restriction Bypass (RVA `0x692CB5`):** Retained and verified the 6-byte NOP patch on `test byte ptr [rax], 1; jz +0x8A`, allowing bipeds (Spartans, Marines, Troopers, ODSTs, Grunts, Jackals, Skirmishers, Elites, Hunters, Drones) and custom vehicles to spawn seamlessly through Reach's Forge subsystem.

### 2. Precise `EnginePlacementData` Frame Alignment
- Corrected the memory structure passed to `object_create_from_params` (RVA `0x7311B8`) to match the exact 80-byte stack layout reversed from `haloreach.dll` RVA `0x692CC0`:
  - `tagDatum`: +0x00
  - `variant`: +0x04
  - `playerContext`: +0x10
  - `playerIndex`: +0x18
  - `team`: +0x1A
  - `posX`: +0x2C
  - `posY`: +0x30
  - `posZ`: +0x34
  - `pitch`/`yaw`/`roll`: +0x3C / +0x40 / +0x44
  - `scale`: +0x48 (1.0f)
- Spawns now compute correct 3D coordinates 3.0 meters directly forward from the camera/player unit.

### 3. VFS Priority A Forge Redirection Fix
- Fixed an issue where mounting a campaign map (e.g. `m20.map` / Sword Base) as a secondary donor heap caused VFS Priority A to mistakenly serve `m20.map` for `forge_halo.map`.
- Added strict filename validation (`forge_halo_normal.map` or `forge_halo_legendary.map`) before serving donor maps for `forge_halo.map`, ensuring Forge World cleanly loads the modified map with the native in-game Forge AI Battleground palette.

### 4. Tag Path Resolution & Custom Menu Ergonomics
- Pre-populated `s_tagPathToDatum` with donor map tag datums for Spartans, Marines, Troopers, ODSTs, Grunts, Jackals, Skirmishers, Elites, Hunters, Drones, Pinky, and the flyable base Pelican.
- Connected `SharedTagCache::InjectScenarioPalette` to the engine cache-step hook so active match tags are dynamically cataloged on every map load.
- Added keyboard shortcuts (`Enter` / `Space` to place, `Esc` to close) and real-time status feedback to the custom Forge menu overlay.
- Maintained removal of obsolete `phantom_mp` and `pelican_o7` tags.
