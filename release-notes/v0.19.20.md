# Project Noble 0.19.20 (Closed Source)

## What's New in v0.19.20

### Pre-Game Lobby Player Listing Fixes
- **Host & Guest Roster Separation:** Fixed a critical bug in lobby joining where joining guests could match and overwrite the host entry on the server when sharing a machine ID or default peer ID. Host entries are now strictly protected and immutable on join.
- **Unique Peer ID Assignment:** Resolved guest peer ID collisions. The server automatically assigns distinct peer IDs for all joining players, guaranteeing that all players appear in separate lobby roster rows.
- **Roster Synchronization on Connect:** The relay WebSocket now immediately pushes the current lobby roster upon connection, ensuring guests and hosts always see up-to-date player listings without waiting for an HTTP poll cycle.
- **Client Local Player Identification:** Rewrote `isLocal` player row evaluation so hosts only evaluate the host row as local and guests only evaluate their own row as local. This prevents guests from inadvertently overwriting remote players' displayed names, emblems, ranks, and colors.
- **Roster Overflow & Scrollbar Fix:** Fixed roster row calculation so small lobbies (< 8 players) no longer generate phantom scrollbars or scroll players off screen into empty "OPEN" rows.
- **Host Auto-Recovery:** Added client-side host self-restoration safeguards during lobby polling and WebSocket events, ensuring the host is never dropped from the player list.
- **Automated Release Pipeline in build.bat:** Updated `build.bat` to automatically invoke `publish-release.ps1` upon successful compilation, ensuring release `.zip` packages are built and published directly from the build script.

## Install

Use the in-game **UPDATE AVAILABLE** banner on the main menu to update automatically, or unzip `Project-Noble-v0.19.20-win64.zip` over your existing installation. Your settings, career progress, and custom appearances are saved locally in `data\userdata` and are never overwritten.
