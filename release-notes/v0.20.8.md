# Project Noble Release Notes --- v0.20.8

### Modded Custom Games (join in progress)
- The guest only accepted a host mod that shipped its own `maps\<scenario>.map`. A content mod (tag, object
  or weapon overrides on a stock map) resolved nothing, so the guest launched the plain map without the
  mod - different content from the host, which the engine then aborts. The host's mod folder is now
  resolved on its own and the guest launches the stock map **with its installed copy of that mod**.
- If the guest does not have the host's mod at all, the launch is refused with a message instead of
  silently starting a vanilla match that would desync.
- Modded Firefight join in progress was already working and is unchanged.

### Merge review: Tyler's Firefight/join commits
- His slot-count fix (no 128-slot expansion for multiplayer; campaign/firefight capped at 16; the engine's
  `publicSlots == 0` launch join lock preserved) is kept as-is. The join-in-progress refusal override is
  now gated on that lock, so it can no longer force a guest into a session the engine has closed for joins.
