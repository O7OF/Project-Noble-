# Project Noble v0.19.76 Release Notes

## Summary
- **Restored Server DB Player ID & Real Authentication:**
  - Restored true database-backed player identity (`users.id`) across the entire client, replacing client-side device hash placeholders.
  - Re-enabled interactive Account Modal on the main menu with full **Log In** and **Register** tabs, secure masked password inputs, and real-time backend verification against `/api/login` and `/api/register`.
  - Added a **Remember Me** checkbox; when checked, secure session tokens are saved locally in settings and automatically re-authenticated on boot.
  - Added **Log Out** functionality in the Account Modal to terminate active sessions and clear credentials.
- **Strict Single-Device Concurrency Enforcement:**
  - Implemented single-instance session locking on the master server. Logging in on a new device while an account is actively logged in on another device returns HTTP 409 (`"Account is already logged in on another device. Please log out on that device to proceed."`).
  - Active presence heartbeats continuously verify session tokens; if a session is invalidated or superseded, the client automatically drops to logged-out state.
- **Database Overhaul & Clean Reset:**
  - Overhauled SQLite database schema on `ServerTestDeploy` with dedicated session tracking (`session_token`, `device_id`, `last_login`, `last_seen`) and performance indices (`idx_users_username`, `idx_users_token`, `idx_friends_user`, `idx_friends_friend`).
  - Ran clean database reset tool (`reset_db.js`) to establish a fresh database state on the master server.
- **Friends List & Invites Fixes:**
  - Overhauled `/api/friends/*` endpoints (`search`, `add`, `accept`, `remove`, `list`) to work with database user IDs and live friendship direction tracking (`incoming`, `outgoing`, `accepted`).
  - Connected `SocialClient` search, add, accept, and remove workflows to the backend database so friend requests and game invites sync and display properly.
- **Fixed Server Browser "16 Total Players" Counter:**
  - Removed client-side scanning of local demo player profiles (`CountLocalKnownPlayers()`) that previously forced the total player counter to 16.
  - Total and online player metrics now load directly from the master server database, accurately reflecting registered users and currently logged-in players.
