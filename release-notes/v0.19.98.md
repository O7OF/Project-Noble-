# Project Noble Release Notes — v0.19.98

### Ping / player identity

- **Fixed the match process ignoring the lobby machine id.** The launcher passes it as `NOBLE_MACHINE_ID=0x…`, but the parser rejected any value starting with `'0'`, so every guest fell back to a random id. That meant the scoreboard, per-peer voice mute and name lookup keyed a different id than the roster and the wire traffic — the reason per-player ping could never be matched and fell back to fake values.
- With the id preserved, the in-match scoreboard can show each lobby member's real measured RTT, the local/host row reads 0, and an unmeasured row shows "-". Verified: a guest launched with `NOBLE_MACHINE_ID=0x1234567890ABCDEF` keeps exactly that id (`guest machine id from lobby` / `Initialized GUEST`).
