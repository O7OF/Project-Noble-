# Project Noble Release Notes — v0.19.96

### Stability

- **Fixed the tester crash after returning to the menu.** Crash dump analysis: access violation reading NULL at `haloreach+0x41E3EB`, after an m10 co-op session returned to the menu. The engine resolves a UI-interface index (0x72 in the dump) and calls `vtable+0x48` on the slot without checking it; the slot was empty and the call dereferenced NULL. A guarded trampoline at `0x41E3E3` keeps the slot load, writes the engine's own "unavailable" sentinel (-1), and skips the call when the slot is null. Verified the guard installs and both a campaign launch and the menu run without faulting.

### Camera

- **One camera tuning application per frame.** The two third-person update hooks can both run for the same observer command; offsets, distance and FOV were being applied twice (and to other observers). Tuning now runs once per command per frame for local user 0 only.
- **Vehicle cockpit path only when vehicle first person is on**, and third-person tuning is skipped while it owns the camera, so the cockpit offset/FOV no longer compound.

### Networking / testing

- **Two instances on one PC:** test-only `-local-port <port>` selects the UDP port, so a host and a guest can run side by side for netcode tests. A host/guest smoke test on 20_sword_slayer completed the join handshake and membership wait on one machine.
