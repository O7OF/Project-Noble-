# Project Noble 0.9.16.28

Server browser and networking update: all three master regions are now one federated cluster.

## Highlights

- **Three master regions:** US West (Oregon), US East (Virginia) and EU West (London, UK).
- **Federated server browser:** every region returns games from all three regions. A game hosted on West, East or UK is visible from any selected region.
- **UK region fixed:** the London service is correctly listed and selected; the old hostname guessing that missed it is gone.
- **URL normalisation:** master-server links copied with a trailing slash (or whitespace) now work correctly; requests are normalised before use.
- **Region selector:** US West, US East, EU West (London, UK) or LAN/Offline, with the current region detected from the configured link.
- **Peer diagnostics:** each region reports its cluster peers and per-region session/player counts for troubleshooting.
- **Crash-only private logs** remain from 0.9.16.27.

## Install

1. Download Project-Noble-v0.9.16.28-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.
