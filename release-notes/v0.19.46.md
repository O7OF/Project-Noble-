# Project Noble v0.19.46 Release Notes

## Auto-Updater Fix
- **No more re-offering the installed version:** The updater compared the latest release tag against a separate numeric patch constant that was never bumped alongside the displayed version (0.19.45 builds reported themselves internally as 0.19.44), so every 0.19.45 install kept offering v0.19.45 as an update. The numeric version is now parsed at compile time from the same `VERSION_STRING` shown on the main menu, so the two can never drift again.
- **Stale download cleanup:** When the client is already up to date, cached update zips under `%LocalAppData%\ProjectNoble\updates` are removed so an old download is never presented as "ready to install".

> Players on 0.19.45 will be offered this update one final time; after installing 0.19.46 the prompt will no longer reappear.

## Version
- Bumped to **0.19.46** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
