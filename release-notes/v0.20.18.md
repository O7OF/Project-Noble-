# Project Noble v0.20.18 Release Notes

## Overview
Project Noble v0.20.18 delivers custom visor finish and armor lights network replication across matches for host and guest peers, prevents visor fallback to stock defaults, and refines third-person crosshair response during camera turns and spins.

## Highlights
- **3rd-Person Dynamic Reticle Polish**: Upgraded screen-space crosshair interpolation with multi-tier adaptive speed (42.0 for walk-cycle stabilization, 85.0 for snappy camera panning and spinning, 135.0 for sweeping turns, and instant snap for flicks/teleports), eliminating crosshair lag while preserving smooth motion.
- **In-Match Custom Visor Replication**: Connected all 30 Spartan visor finishes to appearance records and profile items, eliminating fallback to stock 0..4 visors and synchronizing finishes for both host and non-host clients.
- **Armor Lights & Customization Network Sync**: Synchronized armor lights color and brightness, Spartan/Elite armor components, and armor effects across multiplayer peers using appearance record stamping and live pixel shader constant updates.
- **Biped Shader & Change-Color Updates**: Live match bipeds for remote players now receive exact linear change-colors and shader illumination overrides.
