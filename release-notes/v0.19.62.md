# v0.19.62

## Map variants: JSON saved maps, no more freeze, instant refresh

* A saved map variant is now a **JSON file** in `data\map_variants\<name>.json`: `{"version","name","base_map_id",
  "mode","data"}` where `data` is the variant base64-encoded - the same shape Project Reclaimer uses for its Halo 3
  maps, so a saved map is one small readable file that is easy to back up and share.
* The maps menu reads both: a `.mvar` is used as-is, a `.json` is unpacked next to itself into the `.mvar` the engine
  mounts (only rewritten when the JSON is newer). Verified by hand-crafting a JSON from an MCC variant - it unpacked
  to a `.mvar` and listed.
* **The save no longer freezes the game.** Waiting for the engine's file used to run on the render thread for up to
  eight seconds with 200 ms sleeps; it now runs on a detached thread and the menu returns immediately.
* A save invalidates the Forge map list, so the new map shows up without restarting Noble.

Known open: the engine's own `save_map` still leaves a zero-byte `asq_mglo--1_...temp` behind in
`saves\HaloReach\autosave`, so no bytes are produced yet and the save reports that. Everything downstream of the
bytes - naming, JSON, listing, nesting, launch - is now in place; extracting the current map from the engine is the
remaining piece.
