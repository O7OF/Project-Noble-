# Project Noble Release Notes --- v0.20.2

This release brings settings persistence fixes, controller apply improvements, end-match UI stabilization, non-host post-match crash fixes, and engine lifecycle reliability.

### Settings Menu Save Fix & Diagnostics
- **Settings File Versioning (`settingsVersion: 2`):** Music volume (50%) and custom paddle keys are no longer rewritten to default values upon launch.
- **Robust Save Pipeline:** Implemented per-process temporary files (`settings.json.<pid>.tmp`), `MoveFileExW` atomic replacement, in-place fallback writes, and on-screen alerts if a write ever fails.
- **Save Diagnostics:** Added comprehensive logging for successful settings writes and failure diagnostics.

### Controller Apply in Settings
- **Gamepad A Button Support:** Pressing 'A' on controller while focused on the bottom action box now applies settings immediately with proper focus-ring highlighting.
- **Fresh State Reloading:** The settings panel automatically reloads from disk on re-open to prevent overwriting settings with stale cached edits.

### End-Match UI & Transitions
- **Focus & Control Stability:** Fixed erratic option highlights jumping around when a match ends.
- **Input Parity:** Prioritized virtual cursor and controller focus to eliminate pointer fighting and ensure full user control transitioning back to the main menu.

### Post-Match / After-Action Report & Crash Fixes
- **Unified Settlement Path:** Post-game awards, challenges, and commendations are now calculated consistently between host and non-host clients.
- **Non-Host Crash Prevention:** Fixed non-host crashes on post-match report screens and eliminated black screens following campaign mission cutscenes.
- **Double Payout Elimination:** Prevented duplicate score and credit payouts from conflicting settlement events.
- **Match Watchdog:** Added watchdog polling to ensure the post-game summary opens even if the engine does not report match completion cleanly.
