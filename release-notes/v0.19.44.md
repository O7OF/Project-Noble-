# Project Noble v0.19.44 Release Notes

## Campaign Mission Resolution & Loading Fixes
- **Lone Wolf and Epilogue Map Stem Resolution:** `BlamEngine::ResolveMapId` now prioritizes specific sub-scenes (`m70_bonus` -> 189, `m70_a` -> 188) before matching the root scenario `m70` (187, The Pillar of Autumn). Lone Wolf now correctly loads authentic campaign block `campaign_189_d1.bin`.
- **ONI: Sword Base AI Donor De-confliction:** The cross-map AI/object donor tag cache now detects and skips mounting the active scenario being launched (`SharedTagCache::SetAvoidMap`). This prevents ONI: Sword Base (`m20.map`) from being mounted twice, eliminating the 4% loading stall and infinite menu reload loop.

## Netcode & Backend Synchronization
- **Backend Infrastructure Player Deduplication:** The master server cluster now reports real human player counts without counting internal infrastructure federation nodes.
- **Enhanced Friends Search & Addition:** The backend and client friend systems now support finding and adding players registered via local/device player accounts in addition to database user credentials.
- **Connection Route Stability:** 15-second direct UDP route grace window maintained across loading transitions, eliminating premature connection drops and spurious relay fallbacks.

## Version
- Bumped to **0.19.44** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
