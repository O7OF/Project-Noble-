# v0.19.57

## ONI: Sword Base (`m20`) loading fix & P2P host-handoff suppression in Campaign Co-Op

- **ONI: Sword Base (`m20`)**: Fixed a load stall/crash specific to `ONI: Sword Base` (`m20`). Previously, `SharedTagCache` initialized on Campaign launches and skipped `m20.map` when launching `m20`, falling back to `m45.map` while indexing with `m20.map`'s hardcoded `+0x413DCC` tag-instance offset. `SharedTagCache` is now skipped on Campaign and Front-End Menu launches and strictly validated against `m20.map`'s tag count (`17356`). `"ONI Sword Base"` (without colon) also resolves to Campaign mission `180` (`m20`) rather than multiplayer Sword Base (`196`).
- **Campaign Co-Op session stability**: Hooked `c_network_session::process_host_handoff` (`hr+0x4035DC`) to keep session leadership on the active Noble host instead of sending `msg 16 (host-handoff)` over the pinned relay/UDP transport (which caused guests to leave with `msg 12` and the host to disband with `msg 14`). Merged upstream v0.19.55/v0.19.56 four-player Campaign capacity and co-op peer boot handling (`reason == 9`, `13`, `0x1B`).
