# Project Noble v0.19.42 Release Notes

## Campaign Co-op & Modded Multiplayer
- **Campaign Co-op Launch Fix:** Preserved authentic mission variant blocks (`+0x300`) during campaign launches instead of overwriting them with multiplayer Slayer game variants. Properly initialized machine IDs and player slots (`0x60`, `0xF8`, `0x2F8`, `0xE8`) across pre-built campaign blocks.
- **Modded Map Multiplayer:** Corrected carrier scenario path extraction in VFS so mods with nested paths (e.g. `maps/forge_halo`) load correctly. Added automatic resolution for custom maps located in mod subdirectories (`mods/<mod>/maps/`).

## Puppet Clone & Desync Prevention
- **Restart Match Safety:** Restricted the "Restart Match" pause menu action to solo and host players only. Non-host guests can no longer trigger match restarts, eliminating client duplication and puppet clone spawning.
- **Forge Team Swap Fix:** Removed destructive `object_kill` entity garbage collection on team changes, preventing player biped detachment, controllable clone puppets, and desync in Forge.

## Firefight & Co-op Lobby Clean-up
- **Cooperative Lobby Teams:** Enforced single-team cooperative rules in pre-game lobbies for Firefight and Campaign, completely disabling team selection and team swapping in co-op modes.

## Live In-Game Scoreboard
- **Engine Match Results Synchronization:** Real-time kill, assist, death, and score counters now read directly from the Blam! engine match results table across Firefight, Custom Games, and Forge.

## Netcode & Server Stability
- **Extended UDP Alive Window:** Widened direct UDP connection timeout to 15 seconds to maintain direct peer routes smoothly across map transitions and loading screens without dropping or prematurely falling back to relay.
- **Optimized NAT Hole Punching:** Tuned hole-punch ping intervals (1.5s active / 500ms discovery) for responsive latency tracking and NAT route keepalive.
- **Expanded Packet Queues:** Increased queue limits to 2048 packets and doubled socket drain capacity to 512 iterations per tick, eliminating packet drop spikes during intense matches.

## Server Browser & Social Systems
- **Player Count Accuracy:** Excluded master server cluster infrastructure nodes (East, West, UK) from reported total player counts.
- **Persistent Friends List:** Friends added by username are now saved immediately to disk (`userdata/friends.json` mirrored to AppData) and merged during backend sync so they are never lost.
- **Chat & Menu Input Isolation:** Removed global chat and blocked menu activation (`START GAME`) while the user is actively typing in text boxes or chat overlays.

## Version
- Bumped to **0.19.42** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
