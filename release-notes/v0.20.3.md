# Project Noble Release Notes --- v0.20.3

This release focuses on client optimization, binary efficiency, and streamlined crash diagnostics.

### Performance & Binary Optimization
- **Executable Footprint:** Optimized release binaries with aggressive code folding and compiler-level link-time enhancements.
- **Resource Efficiency:** Reduced binary overhead and streamlined internal runtime structures for faster load times.
- **Package Polish:** Cleaned up unnecessary auxiliary build files from distribution packages for a leaner install footprint.

### Diagnostics & Stability
- **Crash Reporting:** Enhanced minidump generation (`noble-crash.dmp`) next to the executable for faster troubleshooting and diagnostics.
- **Settings Diagnostics:** Streamlined diagnostics reporting in Settings for quick status checks and support reports.
- **Background Overhead:** Removed extraneous file logging overhead during standard release gameplay.
