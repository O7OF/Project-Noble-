# Project Noble Release Notes --- v0.19.89

## No Reach Renaissance file names ship any more
The Elite armour pack and its relocation data now use Noble's own names and format:
- `data\armor\elite_armor.map` (was `rr_elite_pack.map`)
- `data\armor\elite_armor.map.noblereloc` (was `<map>.rrreloc`), a Noble relocation sidecar with the NBRL magic,
  version 1: the same packed-pointer offsets/bases layout, now written and read by Noble.

Removed from the pack and the client: the unused `.rremotes` / `.rrneeds` sidecars, the redundant per-pack `.rrpmcg`
(the embedded item->region table covers the same 191 Armory items), and the RR name on the embedded table, which is
now `spartan_armor_parts.txt`. The Armory and the Elite armour pack behave exactly as before: verified in a
multiplayer match — 127,379 packed pointers relocated and the pack loaded (`extra cache haloreach\maps\elite_armor`).

Note: the Elite armour assets inside the pack are still the same community Elite content; only the file names/format
Noble ships are its own.
