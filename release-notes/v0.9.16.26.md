# Project Noble 0.9.16.26

Readable UI on every panel, plus the native-resolution and live-borderless work from 0.9.16.25.

## Highlights

- **Settings, Career, Server Browser and pause panels scale with the display.** Their shared UI scale was pinned to 1.0 while the menu rendered at 1.8x on a 2880x1620 back buffer, so labels looked half-size and unreadable. The shared scale now follows the overlay height (display-height / 900), matching the rest of the menu.
- **Native-resolution rendering.** The engine renders at the display's native resolution and Windows scales into the window; 720p windowed and 1080p borderless are both crisp.
- **Live windowed/borderless switching.** SETTINGS > GRAPHICS applies immediately; no restart and no swap-chain resize.
- **All front-end screens use the selected menu background.** Your own images in data\ui\custom\backgrounds (or Noble/Reach art) are drawn behind the menu instead of the engine map's camera cuts.
- **Crisp fonts.** Fonts rasterize at 2.5x density, and mouse coordinates are fed in back-buffer pixels after the Win32 backend so hover/click stays under the cursor.

## Install

1. Download Project-Noble-v0.9.16.26-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.

## Notes

- The menu map is compiled into Noble.exe and unpacked to data\menumaps on first launch; the zip contains no loose map, CSV, mods or OBJ files.
- Settings and appearance in data\userdata are preserved by the updater.
- This build supersedes 0.9.16.25, which is removed.
