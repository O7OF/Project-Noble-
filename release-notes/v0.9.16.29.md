# Project Noble 0.9.16.29

Visor colours stay selected, plus the three-region server browser.

## Highlights

- **Visor colours fixed:** choosing a visor finish now sticks in the Armory and saves to your appearance. The equipped selection is kept independently of transient previews, so it can no longer fall back to Default.
- **All 30 visor finishes** remain available through the Armory, with the same rank/credit unlocks.
- **Three-region server browser:** US West, US East and EU West (London) are federated, and games from every region show in the browser.
- **Master links with a trailing slash** now work correctly.
- **Crash-only private release log** and no release diagnostic dumps.
- **Readable Settings/Career/Server Browser panels**, native-resolution rendering and live borderless switching.

## Install

1. Download Project-Noble-v0.9.16.29-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.
