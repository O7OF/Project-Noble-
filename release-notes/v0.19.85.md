# Project Noble Release Notes --- v0.19.85

## Update/reinstall fix
The client updater now only accepts the client zip (`Project-Noble-v<version>-win64.zip`) as an update.
v0.19.84 shipped with a separate Forge World asset whose name also matched the old loose check, so the
updater downloaded the Forge World pack instead of the client and updating/reinstalling appeared to do
nothing. The optional pack is now named `Noble-ForgeWorld-v<version>-win64.zip`, so even older clients
cannot mistake it for the client.

## Also in this build
- Engine Limits: defaulted to Stock for all non-Forge modes (Campaign, Firefight, Multiplayer) to resolve infinite black screens and kicks. Extended limits are dedicated to Forge mode.
- Armory: the Marine and Female Marine previews work from the shipped menu map (no Marine mod required).
- MODS > RECOMMENDED MAPS: optional Forge World pack downloads in-client with SHA256 verification.
- CAMPAIGN: Trooper prototype removed (VANILLA / MODDED only).
- Armory: Spartan <-> Marine species switches apply immediately (only Elite camera flips wait).
- Cutscene recovery stays opt-in (NOBLE_CUTSCENE_RECOVERY=1); mission intros are unaffected by default.
