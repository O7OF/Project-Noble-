# Project Noble Release Notes --- v0.20.13

### Controller Navigation, Smooth Scrolling & Service Record Polish
- **Full Directional Stick Navigation & Thresholds:** Unblocked Left Stick analog navigation across all menus, calibrated cardinal deadzones, and added keyboard arrow key parity so menus navigate cleanly with D-pad, sticks, and keys.
- **Smooth Right-Stick Window Scrolling:** Enabled responsive proportional Right-Stick scrolling in Service Record, Ranks, Challenges, Settings, and Social menus alongside Trigger page scrolling.
- **Service Record & Menu Hover Snap-Back Fix:** Fixed controller tile selection snapping back to the mouse cursor; mouse hover now requires active physical pointer movement before updating menu focus.
- **Service Record Layout & Tactical Visual Polish:** Redesigned the tab bar with native bumper prompts ([LB] / [RB]), flattened Ranks into a clean single-container scroll view, eliminated double scrollbars, and improved grid spacing.
- **Universal Controller Button Activation:** Wired Controller 'A' button to select, activate, and inspect tiles, cards, and dropdown items across Service Record, Challenges, Commendations, and Social menus.
