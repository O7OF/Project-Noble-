# Project Noble Release Notes --- v0.19.86

## Smaller download
The release no longer ships `mainmenu_all.map` (285 MB). Noble now ships only `noble_menu.map`, the rebuilt
menu map that holds the Armory scripts/GLOBALS tables and the Spartan, Elite, Marine and Female Marine
previews. Verified 2026-11-14 with mainmenu_all.map absent: VFS serves noble_menu.map as the menu map, the
Armory finds its GLOBALS table and the Marine tab/customisation work. Base zip: 607 MB -> 356 MB.

## Still available
- Forge World (Pelican, Spectre, Boathog, targeting laser) is the separate optional `Noble-ForgeWorld-*` zip,
  downloadable from the release page or in-client under MODS > RECOMMENDED MAPS.
- The updater only ever takes the client zip (`Project-Noble-v<version>-win64.zip`).

## Also in this line
- Armory: Marine / Female Marine previews work without Marine mods; Spartan <-> Marine species switches apply
  immediately (only Elite camera flips wait).
- CAMPAIGN: Trooper prototype removed (VANILLA / MODDED only).
- Cutscene recovery stays opt-in (NOBLE_CUTSCENE_RECOVERY=1).
