# Project Noble Release Notes --- v0.19.86

## Maintenance & Stability Update
- **Engine Limits:** Enforced stock engine limits by default across all non-Forge game modes (Campaign, Firefight, Multiplayer, Menu) to resolve loading hangs, infinite black screens, and kick-to-menu issues, while keeping expanded object and memory limits dedicated to Forge mode.
- **Updater Hardening:** Hardened update deployment script (`apply_update.cmd`) to ensure any lingering host processes are cleanly stopped before replacing binaries, preventing file lock errors and infinite update loops.
- **Client Archive Validation:** Re-verified update download filters to ensure only full client archives (`Project-Noble-v*-win64.zip`) trigger client updates, cleanly distinguishing from optional add-ons or map packs.
- **Version Alignment:** Synchronized product version and build identity to `0.19.86`.
