# Project Noble v0.19.41 Release Notes

## Build & Publishing Pipeline
- **Separated Build and Publish Scripts.** Decoupled release publishing from `build.bat`. The standard developer workflow via `build.bat` now cleanly compiles and stages `noble-client.exe` without triggering GitHub release uploads. Releases are now packaged and published via a dedicated `publish.bat` script.

## Core Features & Fixes Rolled Forward
- **Full Release Parity.** Fully brings forward all recent enhancements into the official `0.19.41` release channel:
  - Corrected Firefight Beachhead map resolution (`ff50_park` vs `ff10_prototype`).
  - Full-screen high-resolution loading screen backgrounds for all game modes (Campaign, Firefight, Multiplayer, Forge, and custom mods) with clean layout and no overlapping boxes.
  - Container mode presentation suppression: eliminated menu/armory background flickering over Campaign cutscenes and matches.
  - Multi-team scoreboard precision, Forge Red/Blue team pinning, authentic in-match team-change respawning, and vehicle/player camera handling.
  - Universal minidump generation (`noble-crash.dmp` / `noble-dev-crash.dmp`) for both SEH crashes and `std::terminate` exceptions.

## Version
- Bumped to **0.19.41** (`CMakeLists.txt`, `Version.hpp`, `BuildIdentity.hpp`, `noble.rc`).
