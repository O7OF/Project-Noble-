# Project Noble v0.20.30

## Fixes
- **Co-op joining fixed:** Players could be dropped right after joining a campaign co-op game, leaving the host to play alone. This started in v0.20.26, when custom flame colours were added to the player data the game shares with everyone. That data is now left untouched, and every player gets in again.

## Netcode
- **Flame colours over Noble's own connection:** Your custom flame colour now reaches other Noble players through Noble's own network messages instead of the game's player data, so it can never interfere with joining a match in campaign, Firefight or multiplayer.
