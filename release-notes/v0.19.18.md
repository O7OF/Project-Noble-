# Project Noble 0.19.18 (Closed Source)

## 3D Armory Fixes & Included Menu Map

- **Bundled `mainmenu_all.map`:** The release `.zip` now ships `data\menumaps\mainmenu_all.map` and its string tables directly so the 3D Armory pedestal scene works out of the box without any manual file copying.
- **Spartan & Elite Live 3D Armory Preview:**
  - Fixed Spartan helmets, helmet attachments, shoulders, chest pieces (including multi-region grenade belts), wrist, utility, knee guards, and armor effects updating live on the 3D Spartan model in the Armory.
  - Fixed unequipped attachment regions cleanly hiding when switching between single-region and multi-region armor pieces.
  - Fixed `mainmenu_all.string_ids.csv` loading priority and prevented match armor packs from overriding the menu map's model definitions in menu mode.
- **Developer & Release Cross-Play:**
  - Enabled full cross-play between developer builds (`0.19.18-dev`) and release builds (`0.19.18`). Players on matching base versions can discover, join, chat in pregame lobbies, and launch matches together.
  - Server browser displays a gold `[DEV]` tag for servers hosted by developer builds, and reports host versions in game details.
- **Auto-Updater Protection:** Preserves all user settings, appearance, and career files (`settings.json`, `appearance.dat`, `appearance.json`, `career.dat`, `career.json`) during in-app updates.

## Install

Use the in-game **UPDATE AVAILABLE** button to update automatically, or unzip `Project-Noble-v0.19.18-win64.zip` over your existing install (your settings, appearance, and career data are generated locally and never overwritten).
