# Project Noble Release Notes --- v0.19.88

## Armory
- Fixed the Spartan / Elite / Marine / Female Marine previews rendering *behind* the glowing lattice backdrop: the
  lattice mask now uses the screen-aspect scene depth buffer (1920x1080 D24S8) instead of a square shadow-map depth
  buffer, and keeps that buffer across frames.
- Marine and Female Marine previews work from the shipped menu map, with no Marine mod installed.
- Spartan <-> Marine species switches apply immediately; only Elite camera flips settle (~1 s).

## Menu Audio & Balance
- Base music volume scaled down to 15%, with matching default/reset values and migration of legacy 50% installs.
- Stock engine limits enforced for Campaign, Firefight and Multiplayer stability (expanded limits stay in Forge).

## Theater & Engine
- Theater mode saved-film playback support and upstream frontend UI improvements.

## Downloads
- Base release: client + Armory menu map + Elite armour pack (~356 MB).
- Optional `Noble-ForgeWorld-*` pack (~653 MB): Forge World with Pelican, Spectre, Boathog and targeting laser.
  Download it from the release page or in-client under MODS > RECOMMENDED MAPS.

## Earlier in this line
- CAMPAIGN: Trooper prototype removed (VANILLA / MODDED only).
- Cutscene recovery stays opt-in (NOBLE_CUTSCENE_RECOVERY=1).
