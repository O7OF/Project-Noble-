# Project Noble Release Notes --- v0.20.10

### Post-Match Keyboard & Mouse Focus Stabilization
- **[UI] Intentional Mouse Motion Filtering:** Implemented unified motion filtering for physical mouse movement across all menu and post-game screens. Stationary high-DPI mouse sensors no longer produce sub-pixel jitter that steals focus or fights keyboard/gamepad navigation.
- **[UI] Eliminated Focus Fighting:** Keyboard arrow navigation and D-pad selections no longer revert or flicker when the physical mouse is resting over a different button or list row.
- **[UI] Hover Sound Polish:** Suppressed repeated hover sound triggers when the pointer remains over the same button or during focus swaps.

### Post-Match Input Settling & Click Leak Prevention
- **[UI] Transition Settle Guards:** Enforced transition settle windows when entering the post-match results panel and when returning to the launcher Main Menu / Lobby, preventing in-game shooting clicks from leaking through.
- **[UI] Mouse Release Protection:** Mouse clicks are strictly ignored until all physical mouse buttons have been released following match conclusion, ensuring gameplay fire inputs never click through onto menu items.
- **[UI] Accidental Button Skip Protection:** Clicking during the stats reveal sequence now safely skips the reveal animation without triggering the underlying buttons underneath the cursor.

### High-Capacity Session Slot Management
- **[MULTIPLAYER] High-Capacity Match Stability:** Optimized session memory allocation and roster handling for high-capacity multiplayer and custom game sessions.
