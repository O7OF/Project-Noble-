# Project Noble v0.20.20 Release Notes

## Overview
Project Noble v0.20.20 delivers a comprehensive controller navigation overhaul across all menus, submenus, and modals. The settings menu, gamemode options, pre-game lobby, developer console, and account dialog now support seamless D-pad, bumper, and button navigation with clean hierarchical back-out.

## Highlights
- **Settings Menu Two-Zone Controller Navigation**: Fully overhauled Settings panel navigation. The left category list is now navigated vertically with D-pad / left stick Up and Down. Pressing D-pad Right, Enter, or the A button enters the settings rows on the right. Pressing D-pad Left on non-stepper rows or the B button returns focus cleanly to the category column on the left. Pressing B in categories exits Settings. Bumpers (LB/RB) continue to cycle categories instantly from anywhere.
- **Game Mode Options Two-Zone Navigation**: Added clean two-zone navigation between the left category tiles and middle option rules. D-pad Up/Down selects categories; D-pad Right or A enters option rows and action buttons (Save/Reset/Delete); B button or D-pad Left returns to categories.
- **Pre-Game Lobby Bumper & Roster Controls**: Bumpers (LB/RB) now instantly toggle between the Game Options column on the left and the Session Roster on the right. In the roster, pressing D-pad Left or B button returns focus to the options list. Viewing player profile cards can be cleanly closed with the B button.
- **Developer Menu & Cheats Modal Controller Support**: Full D-pad Up/Down navigation across all 6 developer actions (Unlock Armors, Max Credits, Max Rank, Max Everything, Reset Career, Close) with tactical accent focus borders, A button activation, and B button close. In-game cheat overlay now supports smooth controller stick scrolling and B button closing.
- **Account Login / Register Modal Navigation**: Bumpers (LB/RB) quickly switch between Log In and Register tabs, and the B button dismisses the modal cleanly.
