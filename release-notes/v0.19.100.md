# Project Noble Release Notes - v0.19.100

### Smooth Local Cameras (3rd-Person & Vehicle 1st-Person)

- **Eliminated 3rd-person & zoom camera jitter:** Replaced Present-frame skip caching in `ApplyThirdPersonCameraTuning` with nested-hook depth and untouched-buffer guards so multi-tick or sub-60 FPS frames never alternate between tuned and untuned offsets/FOV.
- **Smoothstep QPC zoom interpolation & controller zoom:** Advanced third-person zoom blending using wall-clock `QueryPerformanceCounter` deltas with Hermite smoothstep easing, cached `thirdPersonZoom` in `CameraTuning` to eliminate per-frame snapshot allocations, and forwarded controller zoom (`0x0080` after `PadLayouts::Apply`) cleanly alongside M&K.
- **Strictly local per-client cameras & finite guards:** Filtered all third-person and vehicle first-person camera overrides to local `userIndex == 0` / local unit only (`s_getLocalUnit(0)`), verified parent vehicle attachment (`vehicleDatum != -1 && vehicleDatum != unitDatum`) before cockpit placement, and added `std::isfinite` bounds checks across camera positions and FOV.

### Match-End UI Control, Focus Stability & Smooth Transitions

- **Fixed Game Over & Post-Match UI losing control / wild focus highlights:** Added `ImGuiWindowFlags_NoNavInputs | ImGuiWindowFlags_NoNavFocus` to Noble's custom-navigated Pause, Connection Lost, and Game Over panels so ImGui's internal nav cursor never fights manual button selection; moved `s_padButton`, arm delay, countdown cancellation, and guest auto-return flags to file scope reset cleanly in `ShowGameOver()` and `CancelGameOver()` with a post-match input settle and key-release guard.
- **Eliminated Virtual Cursor vs physical mouse fighting:** Ran `UiPad::Feed` before physical mouse injection in `PauseMenu::RenderImpl`, `FrontEndMenu::RenderOverlayImpl`, and `UIManager::BeginFrame`, suppressed physical pointer injection while Virtual Cursor owns the cursor, allowed D-pad navigation without forcing VC click capture, and refreshed physical cursor baselines in `ResetAfterMatch()`.
- **Clean menu return & smooth UI transitions:** Suppressed stray hover deltas while window focus settles back into `FrontEndMenu` (`ContainerMatchEnded`), reset active ImGui focus and orphaned screen pickers across screen changes, and added a fast smoothstep transition fade between menus.
