# Project Noble Release Notes --- v0.19.102

This build collects the fixes made after v0.19.101. Everything here was already on the dev line; this release is what
puts it in the public download and the updater.

### Campaign / Custom Games map pickers

- **Mods are collapsed sections again**: the MODDED tabs (Campaign, Custom Game, Firefight and the lobby map select)
  show one compact banner per mod with its map count instead of every map tile of every mod. Click the banner (or
  Accept/Y) to expand it; click the mod heading row (`FOLD`) to collapse it again.
- **Campaign MAX PLAYERS**: the Campaign screen now has a MAX PLAYERS row (4 / 8 / 12 / 16) and HOST CO-OP passes that
  value to the lobby. It used to be hard-coded at 16 with no UI.
- **Campaign search box no longer clipped** on narrow/4:3 UIs.
- **The "?" placeholder is gone**: the expanded-map header used an em-dash glyph the game font does not have
  ("FORGE WORLD ? BASE MAP & VARIANTS"); it now uses an ASCII hyphen.
- Map search still expands every matching mod/variant while filtering.

### Visors

- **Extended visor finishes no longer render white.** The engine only has five real visor slots (Default / Silver /
  Blue / Gold / Black); the extra Armory finishes were being stored as out-of-range slots, which the renderer draws as
  white. Every finish now writes a valid stock slot (nearest stock colour), while the Armory itself still shows the exact
  finish. Note: exact custom colours such as Blood Orange are still Armory-only for now; matching them in a match needs
  further engine work (documented in the handoff).

### Settings

- **Settings > Game Options sliders line up**: each camera slider track used to be sized from its own value text
  ("OUT 120 %" rows ended further left than "100 %" rows), so the wheels looked offset. All camera tracks now share one
  start, length and value column, and long labels are ellipsised instead of running under the track.
- **Saving a FOV change in the front-end no longer zooms the Armory model**: FOV is a match setting and is applied when
  a match starts; in-match changes still apply live.

### Server browser

- Details-pane mod/version warnings wrap inside the panel and are shown under the server address; the primary action
  (`DOWNLOAD MOD & JOIN`) is visible without scrolling.

### Also

- The release still ships the optional Forge World pack as a separate asset (`Noble-ForgeWorld-v0.19.102-win64.zip`).
- Campaign co-op / Firefight co-op launch blocks still declare at most 16 players; work on the larger player counts is
  tracked separately (multiplayer is the last item on the current queue).
