# Project Noble v0.19.34 Release Notes

## Modded Map Multiplayer & Synchronized Launch Fixes
- **Modded Map Loading in Forge & Custom Games:** Resolved the critical bug where modded maps would load indefinitely when attempting to play with other peers in Forge and Custom Games:
  - Fixed host-to-guest launch signaling by broadcasting `map_override`, `mod_folder`, and `mod_id` through the Master Server lobby launch REST endpoint and real-time WebSocket protocol.
  - Implemented smart guest-side map and mod resolution on launch (`choice.mapOverride` and `choice.modFolder`): checks local file paths, Steam Workshop directories, user mod vaults, and installed mod catalogs.
  - Passed `-map-override` and `-mod` directly to the guest's relaunch command so both host and guest run against identical map files, ensuring tag checksum and scenario synchronization succeed without hanging.

## Networking, Global Chat & Messaging
- **Global Chat & Direct Messaging:**
  - Expanded `SocialOverlay` with two new channels: **Global Chat** (`kGlobal`, gold banner) and **Direct Messaging / Whispers** (`kDirect`, cyan banner).
  - Added full slash-command parser supporting `/w <player>`, `/whisper`, `/dm`, `/msg`, `/r` (reply to last sender), `/g` (global), `/all`, `/team`, and `/party`.
  - Added one-click `MESSAGE` action in the Friends list on the Social screen to open a direct whisper channel immediately.
  - Enabled Global Chat to be opened directly from the Main Menu (`Screen::Main`) and during menus via the `[Y]` hotkey or gamepad button prompt.
  - Propagated target player names through the `NetworkTransport` packet relay.

## Controls & In-Game Menu UX
- **Forge Controller Navigation:** Fixed controller Button B in the in-game Forge Menu so pressing B cleanly exits/closes the menu and plays the back sound while zeroing out gamepad triggers and buttons to avoid unintentional jumps or crouches.
- **Keybinding Conflict Resolution:** Prevented settings category switching when rebinding keys to `Q` or `E` by implementing an input key swallow guard that drains ImGui key queues until the rebound key is released.
- **Mouse Scroll Dampening:** Added dampening and notch clamping (`std::clamp(wheel, -1, 1)`) across menus to prevent hyper-speed scrolling.
- **Player Name Persistence:** Automatically persists custom player name and service tag edits to `DeviceIdentityStore` and `AuthClient` immediately upon editing, ensuring quitting directly in-game never reverts profile names.

## Audio & Music Polishing
- **Menu Music In-Game Isolation:** Added `ReachAudio::IsMenuMusicEnabled()` state query; properly silenced menu music on game launch and guarded `PlayMenuMusic()` in settings `Apply()` and `Discard()` so applying settings mid-match never triggers bursts of menu music or overrides in-game audio.
- **Zero-Volume Master Mute:** Updated `ProcessAudio::ApplyAll()` to zero out audio volumes immediately when `masterMute` is enabled.

## Gametypes, Teams & In-Game Pause
- **Custom Gametypes Reading & Decoding:** Removed the rigid `0x5329` size check in `VariantRules::Decode()`, automatically zero-padding smaller custom RVT files so custom game variants decode cleanly.
- **Gametype Categorization:** Added proper categorization for "Plus / TU", VIP, and Action Sack gametypes.
- **Local Game Pausing:** Fixed local/solo game pausing by invoking `SetLocalSimulationPaused(true)` and Blam! simulation pause (`game_speed 0`) whenever opening the pause menu in a local match, and resuming cleanly upon closing.
- **In-Game Change Team:** Enabled the "CHANGE TEAM" option in the pause menu for all multiplayer, custom, and Forge matches, executing `player_override_team` and updating the scoreboard roster.
- **Social Settings Category:** Added a dedicated "SOCIAL" tab in the Settings Panel housing voice chat master toggles, speech mode (Push to Talk vs Auto Speak/Open Mic), Mute All Players, Voice Overlay indicator, Voice Volume, Talk To channels, device pickers, and Text Chat toggles.
- **240 FPS Limit:** Verified and exposed the 240 FPS frame cap option for high-refresh 240 Hz displays.
