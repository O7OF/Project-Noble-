# Project Noble Release Notes --- v0.19.93

## Tile-Based Menu, Map Picker & Server Browser Overhaul
- **Tactical Map, Mode, Campaign, Firefight & Mod Pickers:**
  - Replaced legacy list selectors with Reach-styled tactical tiles (`NobleUi::DrawTacticalFrame`) featuring crisp, non-upscaled map preview artwork (`UiArt::DrawCoverCrisp`), expandable map variant sub-lists, and unified controller + mouse & keyboard navigation.
  - Added mod preview image discovery (`WorkshopManager::ModItem::previewImage`) for the modded map picker.
- **Server Browser Overhaul:**
  - Redesigned Server Browser layout with sort options (Players, Ping, Name, Map), mode/availability filters, clean modal handling, and full D-pad/stick/M&K navigation.
- **Duplicate Launch Protection:**
  - Added active child process tracking in `Relaunch::StartChildMatch` so repeated launch inputs cannot spawn duplicate match client windows.

## Netcode, Lobby Chat & Backend Bandwidth Optimization
- **Host-Driven UDP Voice & Lobby Chat:**
  - Routed in-match `NVOX` voice frames and `NBCJ` lobby/chat control traffic directly between Host and Guests over UDP instead of relaying continuous match traffic through the backend WebSocket.
  - Scoped text chat to Lobby / Team / Party channels inside the Pre-Game Lobby and pause overlay (removed Global chat and Direct Messages).
- **HTTP Caching & Reduced Background Polling:**
  - Enabled WinHTTP gzip/deflate decompression and `ETag` / `If-None-Match` (`304 Not Modified`) response caching for browser, session, and lobby endpoints.
  - Eliminated per-frame player count requests in `ServerBrowser`, removed redundant post-register heartbeats, throttled lobby/heartbeat/social background polling intervals, and added in-flight guards on friends/invites refreshes.
