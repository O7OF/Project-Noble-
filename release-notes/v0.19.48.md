# v0.19.48

## Firefight-canvas mod maps now play from the lobby, solo or hosted

Installation 04 and Glacier AI Battleground no longer sit on a black screen. They are listed where their manifest
says they belong (Multiplayer), and launching one from the pre-game lobby plays it in Forge - the mode Reach actually
renders these maps in, with the object palette available.

Three fixes made this work end to end:

- **The map's game type is aligned with the launch.** Reach's map loader rejects a map whose declared game type
  differs from the one the launch asks for. These mods are built on Firefight canvases and declare `0x7D2` while a
  Forge launch asks for `0x2760`; Noble now aligns the loaded header with the request before the loader compares
  them.
- **The map is presented as multiplayer at launch time, not just from the command line.** The map info the engine
  reads is now written from `BlamEngine::LaunchMap`, so a lobby launch gets the same treatment as a direct one.
- **Firefight-canvas mod maps launch through Forge.** In Firefight or Slayer they load and report a running session
  but render black; MCC plays these mods in Forge for the same reason, and a Firefight-tab request is routed there
  automatically.

Verified: Installation 04 and Glacier both render and run when launched as Firefight or as a custom game, and Forge
World and Boneyard are unchanged.
