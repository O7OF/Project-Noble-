# Project Noble 0.19.23 (Closed Source)

## What's New in v0.19.23

### Forge AI & Object Spawning Dispatch System
- **Thread-Safe Simulation Placement Dispatch:** Fixed an issue where attempting to place or spawn Forge items directly from the DirectX 11 render thread triggered engine TLS access violations and reported "Engine create hook pending." Object placement requests from the UI or Gamepad are now safely queued and processed on the engine's 60 Hz simulation thread (`FillLocalInput`) inside an authentic Blam! TLS context.
- **Structured SEH Exception Isolation:** Guarded engine object creation routines with structured exception handling (`SafeCallForgeSpawn`), preventing memory access faults and ensuring unhandled engine state failures fail gracefully without crashing the client.
- **Enhanced Palette Discovery & UI Feedback:** Updated Forge palette configuration loaders to check multiple local candidate paths, and improved prompt messaging to clearly reflect queued placement status and active world entity instantiation.

## Install

Use the in-game **UPDATE AVAILABLE** banner on the main menu to update automatically, or unzip `Project-Noble-v0.19.23-win64.zip` over your existing installation. Your settings, career progress, and custom appearances are saved locally in `data\userdata` and are never overwritten.
