# Project Noble 0.19.17 (Closed Source)

First closed-source release. The open-source **Halo: Reach Community Edition**
line is frozen at 0.9.16.37 and is no longer updated.

## New master-server cluster

Three regions, federated into one game list:

| Region | URL |
|---|---|
| US East (Virginia) | https://projectnobleeast.onrender.com |
| US West (Oregon) | https://projectnoblewest.onrender.com |
| UK (London) | https://projectnobleuk.onrender.com |

Pick the closest region in the server browser. Every node shares its session
list with the other two, so a game hosted on any region is visible everywhere.

## Compatibility

0.19.17 speaks **protocol 2** and is deliberately **not compatible** with
0.9.16.x builds:

- the cluster refuses 0.9.16.x registration, heartbeat, join and lobby requests;
- the game list hides sessions from other builds;
- the relay moved to `/ws/relay2`;
- the Reach session id changed, so a direct-UDP join from an old build fails too.

## Install

Unzip over your existing install (settings and appearance are kept), or into a
fresh folder and copy `data\userdata` across. Requires Windows 10/11, a D3D11
GPU, and Halo: The Master Chief Collection (Steam) with Halo: Reach installed.
