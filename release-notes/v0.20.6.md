# Project Noble Release Notes --- v0.20.6

### Settings resetting to default
- Fixed the settings migration that ran on every start: Noble mirrors `settings.json` into
  `Documents\Noble Launcher\data` and `%APPDATA%\ProjectNoble\data`, and on the next launch the migration
  copied the copy with the newest timestamp back over the saved file. When that copy was an old default
  file (or a mirror that failed with access denied), the player's volume, FPS limit, keybinds and the rest
  came back as defaults. Migration now only runs on a first start, when the install has no settings file
  of its own, so a saved file is never replaced by a copy from another location.

### Joining a game in progress (Firefight)
- The host no longer sends refusal reason 3 (join in progress) for an active Noble session; the engine's
  own join handshake completes instead of dropping the client back to the main menu.

### Also in this line (v0.20.4 / v0.20.5)
- Guests see the full lobby roster and player count on the loading screen.
- Scoreboard: only the local player is marked "YOU"; per-player service tags; ping resolved for joiners.
- Invite join connects directly and shows the host's real player name.
- Server browser shows the same version string as the main menu.
- AMD CPU performance: power throttling disabled, above-normal process/render-thread priority.
