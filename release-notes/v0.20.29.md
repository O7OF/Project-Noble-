# Project Noble v0.20.29

## Performance
- **Higher match frame rates:** While a match is running, the menu process no longer keeps a full CPU core busy, so that core goes to the game. On a Ryzen 5 5600G with an RTX 4070, the busiest spot on the map went from about 70 FPS to 110-120 FPS.
- **Lighter per-frame work:** Flame colour tinting skips its work when nothing needs tinting and checks each texture once per frame instead of on every draw. Frame pacing and the FPS counter read their settings a few times a second instead of every frame.

## Audio
- **No more silent launches:** Noble clears a leftover Windows volume-mixer mute at launch. Closing the game while it was in the background could leave it muted in the Windows mixer on every later launch.
