# Project Noble v0.19.31

## Developer Cheats & Campaign Local Player Resolution
- **Game-Tick Execution Filter Fix:** Removed `userIndex != 0` filter in `DevCheats::GameTick`. In Campaign matches, the engine passes non-zero or user indices into the tick hook at `0x61A38`, which caused cheats to be skipped entirely.
- **Robust 3-Tier Local Player Resolution:**
  1. `player_mapping_get_unit_by_output_user(0)` (RVA `0x53EF8`).
  2. Engine players array at `root + 0x18` (0x490-byte stride, unit handle at `+0x28`).
  3. Object pool placed biped scan (`type == 0` with non-zero coordinates).
- **Direct Weapon Give:** Spawn weapon directly at player hands/chest level (`player.pos + player.fwd * 0.8f + [0, 0, 0.4f]`) and call native `s_unitAddWeapon(player.unitHandle, 0, handle, 0)`.
- **Super Speed & Jump:** Applied horizontal position offset along WASD forward/right vectors so character controller / Havok physics cannot clamp sprinting velocity; Super Jump boosts vertical velocity on Space press.
- **Freecam Controls:** Suppressed character movement keys (W, A, S, D, Space, Ctrl, Shift) while Freecam is active so player Spartan does not walk away.
- **Stock Limit Awareness:** Documented engine limits on object and proxy pools in Campaign.
