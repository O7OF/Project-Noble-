# v0.19.49

## Lobby joins no longer drop you at random

A guest used to leave the pre-game lobby the first time the lobby-state poll did not come back cleanly. One slow or
failed request (a timeout, a 502, a relay hiccup) sent the player straight back to the server browser, which looked
like being auto-kicked the moment you entered a lobby.

The poll now tolerates failures: it retries, only leaves after three consecutive failures, and logs both the HTTP
status it saw and whether the lobby was actually closed by the host (or timed out on the master server) rather than
unreachable. When a guest does leave, the reason is written to the log.

Also in this build: the release client's version string, so both players in a lobby report the same build.
