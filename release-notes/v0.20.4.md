# Project Noble Release Notes --- v0.20.4

This release includes binary performance optimizations, streamlined diagnostics, and overall client polish.

### Performance & Optimization
- **Binary Footprint:** Advanced code folding and link-time optimizations reduce executable memory usage and improve startup times.
- **Package Cleanup:** Streamlined distribution package contents for a leaner, faster download and installation.

### Diagnostics & Stability
- **Crash Reporting:** Enhanced lightweight crash dump generation (`noble-crash.dmp`) without background log file overhead.
- **Diagnostics Reporting:** Updated Settings diagnostics to quickly report system and crash dump status.
