# Project Noble Release Notes --- v0.20.4

This release fixes multiplayer visibility issues, the scoreboard, server-browser version display and frame
rate on AMD processors.

### Loading Screen (all players)
- **Guests now see the whole lobby while loading.** The loading roster used to be sent only to the host process, so joining players loaded alone in the dark. Every process now receives the roster and the player count, and the loading screen shows the same list of names on host and guest alike.

### Scoreboard
- **Only you are marked "YOU".** The engine's results table and the TLS player array could both flag rows, and on a client that marked every row as local.
- **Service tags show the right tag per player** instead of the local tag on every row.
- **Ping shows for joining players.** Rows that arrived without a machine id are matched to the measured RTT by player name, with the existing two-player fallback kept.

### Joining
- **Invite / join-by-code uses direct connect** to the host's lobby, and the lobby no longer shows the server-browser lobby name as the host's player name: the host's real player name is taken from the lobby roster.
- **Server browser shows the same version as the main menu.** The VERSION row and mismatch warnings now use the display version; the wire build tag is still used for compatibility checks only.

### Performance
- **AMD CPU frame rate:** the process now opts out of Windows power throttling (EcoQoS), runs above normal priority, keeps the system awake, and the render thread is raised above normal priority. This addresses the case where Ryzen systems on the same GPU ran far below Intel systems.

### Build
- Version bumped to 0.20.4.
