# Project Noble v0.19.27 Release Notes

### Forge World Loading & Donor Map Fixes
- **Vanilla Forge World Restoration:** Removed blanket VFS interception of `haloreach\maps\forge_halo.map`, ensuring stock Forge World (`forge_halo.map`) resolves directly to the MCC installation without being forcefully replaced with the AI Battleground mod (`forge_halo_normal.map`).
- **Campaign AI Donor Map Exclusivity:** Refactored `SharedTagCache::DiscoverDonorMap` to strictly mount stock campaign maps (`m20.map` / Sword Base, `m45.map`, `campaign.map`), eliminating all search candidates and fallback scanning for `forge_halo_normal.map` and workshop mod `2899383598`.
- **Campaign Pointer Base Protection:** Removed dynamic modification of `kPointerBases[2]` at RVA `0x4E39F20`. Preserving slot 2 prevents corrupting the engine's internal `campaign.map` resource mapping, allowing multiplayer maps and Forge World to resolve shared campaign assets cleanly.
- **Concurrent File Sharing & Safe RAM Patching:** Configured `CreateFileW` with `FILE_SHARE_READ | FILE_SHARE_WRITE` in `SharedTagCache::MountFile` to avoid Win32 file locking conflicts, and wrapped the in-memory `wraith_d` Pelican seat label replacement with `VirtualProtect` for page-safe RAM patching.
