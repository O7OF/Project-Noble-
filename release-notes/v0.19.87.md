# Project Noble Release Notes --- v0.19.87

## Armory fix: character rendered behind the lattice
The Armory lattice backdrop picks the engine's scene depth buffer to mask itself behind the character. It could
pick the square 1600x1600 shadow-map depth buffer instead of the 1920x1080 scene depth, so the lattice was drawn
over the Spartan, Elite, Marine and Female Marine previews. The chosen scene depth is now the one matching the
screen aspect, and it is kept across frames (the engine does not clear it every frame).

## Menu Audio & Balance
- **Base Music Volume:** Scaled base music volume down to 15% (0.15) to eliminate uncomfortably loud main menu music playback.
- **Audio Settings Defaults:** Aligned default Music volume slider and reset targets in the Settings Audio panel with the new 15% base level, and automatically migrated existing configurations using the legacy 50% default to 15%.

## Theater & Engine
- Includes theater mode saved film playback support and upstream frontend UI improvements.
- Maintained stock engine limits enforcement for Campaign, Firefight, and Multiplayer stability.
