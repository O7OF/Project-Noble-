# Project Noble v0.20.37

## Pre-Game Lobby UI Cleanup & Redesign
- **Organized Tabs:** Reorganized host pre-game lobby options into clean `[ MATCH SETUP ]` and `[ LOBBY SETTINGS ]` tabs. Match setup keeps primary game type, map, and game options front-and-center, while lobby moderation, joins, rules, word filters, and ping limits are neatly grouped in Lobby Settings.
- **Immediate Start Match:** Placed `START GAME` / `START FIREFIGHT` / `START CO-OP CAMPAIGN` / `START FORGE` directly at Row 0 for the host for instantaneous match launch.
- **Zero Card Overlap:** Established hard vertical bounds and strict clipping so option lists can never draw over or collide with the Friends card or Hosting P2P invite code card regardless of resolution.
- **Smooth Scrolling & Pad Navigation:** Full mouse-wheel and gamepad right-stick scrolling with a sleek tactical scrollbar thumb. Up/down navigation automatically brings focused items into view. Pressing B / Back or Esc in Lobby Settings returns cleanly to Match Setup.
