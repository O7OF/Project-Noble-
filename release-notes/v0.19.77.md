# Project Noble v0.19.77 Release Notes

### Highlights
- **Hosting & UPnP Resolution:**
  - Initialized UPnP and SSDP discovery at engine boot rather than delaying until the server browser is opened.
  - Asynchronously forwarded UDP port `11774` in the background and enhanced `QueryPublicIPWithIpify()` to query `api4.ipify.org` first, preventing UI stalls on the render thread.
  - Prevented stale lobbies and ghost sessions from consuming host IP capacity on the master server by pruning expired sessions and increasing the per-IP session quota to 8.
- **NAT Type & Relay Detection:**
  - Updated the server browser and networking stack to classify NAT type accurately (`OPEN`, `MODERATE`, `STRICT`) using live UPnP port-mapping state and IPv4 reachability.
  - Implemented automatic WebSocket fallback relay (`/ws/relay2`) for clients behind moderate or symmetric NAT.
- **Multi-Channel Chat Overhaul:**
  - Added dedicated channels: **Global** (network-wide across all connected clients), **Lobby** (all players in current session), **Team**, **Party**, and **Direct Message** (whispers via `/w <player> <msg>` or `/r <msg>`).
  - Added background global relay connectivity so players can whisper and chat globally directly from the main menu, armory, and server browser.
- **Account Persistence & Role Stability:**
  - Fixed `[DEV]` and `[TESTER]` role tags flickering or popping out by persisting tester roles in settings, passing `-account-tester` and `-remember-account` across match relaunches, and preventing unauthenticated presence pings from resetting active roles.
  - Enforced case-insensitive username uniqueness on registration and added `/api/account/change-name` and `/api/account/check-name` endpoints.
  - Protected "Remember Me" credentials from accidental invalidation during temporary network hiccups or server restarts.
- **Networked Mod & Custom Map Synchronization:**
  - Fixed join flow from friend invites so invite payloads carry verified host endpoints and session IDs.
  - Ensured custom maps and mod overrides across Campaign, Firefight, Forge, and Multiplayer synchronize over the network.
