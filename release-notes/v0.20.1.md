# Project Noble Release Notes --- v0.20.1

This update includes career progress and challenges persistence hardening, pause menu enhancements, host lifecycle stability fixes, and engine hooks synchronization.

### Career & Challenges
- **Progress Tracking & Persistence:** Hardened career stat recording, XP calculations, and challenge progress tracking across sessions.
- **Service Record Integration:** Improved challenges layout and visual parity with the service record.

### Pause Menu & In-Game UI
- **Visual & Navigation Polish:** Enhanced tactical framing, controller/keyboard navigation, and responsive scrollwheel support.
- **Roster & Emblems:** Seamless emblem and loading background rendering with zero UI overlap.

### Host Lifecycle & Engine Stability
- **Engine Patches & Hooks:** Stabilized host initialization, lobby hooks, and memory boundaries during match transitions.
- **Multiplayer State Consistency:** Guarded against session state desync when returning to the lobby or main menu.
