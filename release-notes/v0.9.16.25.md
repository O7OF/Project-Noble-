# Project Noble 0.9.16.25

Crisp rendering everywhere, live windowed/borderless switching, and a stable custom menu background.

## Highlights

- **Live borderless full screen.** Windowed and borderless now switch immediately from SETTINGS > GRAPHICS; no game restart. The window is restyled/resized while the engine keeps running.
- **Native-resolution rendering.** The engine renders at the display's native resolution (or the window's, if larger) instead of at a small window size. Windows then scales the image into the window, so menu text, HUD, subtitles and gameplay are crisp in both 720p windowed and 1080p borderless.
- **Custom menu backgrounds actually show.** Every front-end screen now draws the selected menu background: your own images from data\ui\custom\backgrounds, or Noble/Reach art. The engine map's camera cuts are no longer visible behind the menu.
- **Armory stays live and large.** The 3D Spartan/Elite remains the real in-engine model with the full-body framing and menu supersampling from 0.9.16.24.
- **Hover/click coordinates fixed.** The overlay now feeds the mouse in back-buffer pixels after the Win32 backend has had its turn, so buttons no longer stay "hovered" or react at the wrong position when the window and render sizes differ.
- **More display control.** Window mode and window size apply live; the graphics page explains that rendering stays at native resolution. Existing options (FPS limit, VSync, FXAA, brightness, FOV, menu background) remain.

## Install

1. Download Project-Noble-v0.9.16.25-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.

## Notes

- The menu map is compiled into Noble.exe and unpacked to data\menumaps on first launch; the zip contains no loose map, CSV, mods or OBJ files.
- Settings and appearance in data\userdata are preserved by the updater.
- If you downloaded 0.9.16.24, this build supersedes it; the older release will be removed.
