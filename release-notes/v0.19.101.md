# Project Noble Release Notes --- v0.19.101

### New Loading & Waiting Screen (Campaign, Custom Games, Forge, Firefight)

- **Redesigned in-match loading screen**, built around the reference layout: a letter-spaced `LOADING` / `WAITING FOR
  PLAYERS` / `WAITING FOR HOST` title top-left, the map name with the loading percentage or the joined/expected player
  count, a thin progress bar, the lobby roster (host first, `(YOU)` on the local player, `HOSTING` / `READY` /
  `WAITING...` per row) and `PRESS T FOR CHAT` when online. The mode name sits top-right (`CAMPAIGN` / `CUSTOM GAME` /
  `FIREFIGHT` / `FORGE`).
- **Map pictures are no longer zoomed.** The picture is drawn complete at its own aspect ratio over a soft, dim copy
  of itself; before this, the 668x292 Reach map previews were stretched across the whole screen, which is what made
  them look zoomed in.
- **Reach's loading-screen look**: the "Auntie Dot" diamond grid sits behind the map picture and drifts slowly with a
  travelling bright wave, with the Noble Team emblem bottom-left and the UNSC emblem bottom-right.
- **Waiting for players actually shows now.** When a host is waiting at the remote-player membership barrier after the
  engine's own loading screen has ended, the screen stays up as `WAITING FOR PLAYERS` with the live count instead of a
  black frame with only the FPS counter.
- **Roster scales with the lobby**: one column for small lobbies, two columns at 16 players, and a compact
  multi-column grid for 32 / 64 / 128-player sessions, with `+N MORE` if a lobby is ever larger than the space allows.

### Server Browser

- **Blue-glass layout is the default**: larger server cards, cyan chrome, bigger map artwork, no amber brackets.
  The previous tactical cards and a compact one-line table layout remain available with `-server-browser-style 1|3`.
- **Modded sessions are obvious**: a cyan `MOD` badge when the required Workshop item is installed, an amber
  `MOD - NOT INSTALLED` badge when it is not, and `MOD: <title>` on the map/mode line.
- **Workshop download prompt**: GAME DETAILS names the required mod, says whether it is installed, and the primary
  button becomes `DOWNLOAD MOD & JOIN`; that opens the Workshop dialog (title, author, size, subscribers, preview
  picture) and installs it before joining.
- **Version issues are called out** in the details pane: red for a build you cannot join and amber for a compatible
  build-string difference (e.g. dev vs release).
- **Warnings wrap inside the details pane** and sit under the server address, so nothing is clipped under the
  scrollbar and the join button is visible without scrolling.
- The selected server always stays on a session that is visible in the filtered list.

### Also in this build

- Includes the v0.19.100 camera and match-end fixes: jitter-free third-person and vehicle first-person cameras,
  smooth QPC zoom blending, controller zoom, and stable post-match UI focus/cursor handling.
- Forge World remains a separate optional download (`Noble-ForgeWorld-v0.19.101-win64.zip`), also available in-client
  under MODS > RECOMMENDED MAPS.
