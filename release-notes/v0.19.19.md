# Project Noble 0.19.19 (Closed Source)

## What's New in v0.19.19

### UI Scaling & Display
- **UI Scale Slider:** Added UI Scale control in Video Settings (75% to 150%) that scales menus, HUD elements, and pause overlays cleanly across 1080p, 1440p, and 4K displays.
- **High-DPI & Resolution Picker:** Real resolution handling on scaled displays with an in-game resolution selector.
- **Frame Rate Caps:** Added 240 FPS and 360 FPS options, default frame limit to display refresh rate, and capped menu rendering at 60 FPS to keep GPU utilization cool.

### Game Options & Custom Game Types
- **Game Options Editor:** Comprehensive, searchable, foldable game options editor with categorized settings (Respawn, Objectives, Spawning, General), preset loading, changed-only filtering, and real-time description tooltips.
- **User Variants & Categories:** Full scan support for user-created `.bin` variants, including VIP and Action Sack game types.

### Gameplay & Controls
- **Change Team:** Toggle teams directly in pre-game lobbies and the in-match pause menu.
- **Singleplayer Pause Freeze:** Opening the pause menu in a local, singleplayer match now cleanly freezes gameplay simulation.
- **Input & Hotkey Capture:** Rebinding keys swallows all menu shortcuts until bound or cancelled; mouse wheel scrolling is tuned to one notch per row.
- **Immediate Settings Persistence:** Player identity, gamertag, service tag, and preferences save immediately upon editing.

### Audio & Ambience
- **Menu Music Handling:** Menu music stops cleanly upon entering a match and resumes in menus; volume and mute settings apply before any audio playback starts.

### Cross-Play & Multiplayer Netcode
- **Developer & Release Cross-Play:** Developer builds (`0.19.19-dev`) and release builds (`0.19.19`) can discover, join, chat in pre-game lobbies, and launch matches together.
- **Server Browser Badging:** Displays a gold `[DEV]` tag for servers hosted by developer builds, with detailed host build reporting in server details.
- **Bundled 3D Armory Map:** Release package bundles `data\menumaps\mainmenu_all.map` and string tables for out-of-the-box 3D Spartan and Elite armor customization.

## Install

Use the in-game **UPDATE AVAILABLE** banner on the main menu to update automatically, or unzip `Project-Noble-v0.19.19-win64.zip` over your existing installation. Your settings, career progress, and custom appearances are saved locally in `data\userdata` and are never overwritten.
