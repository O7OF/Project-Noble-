# Project Noble 0.9.16.27

Private release logs and the readable-UI/native-rendering improvements from the previous builds.

## Highlights

- **Normal play leaves no log file contents.** Release builds only record errors and crash summaries; startup, network, menu and gameplay details are not written.
- **No technical addresses or endpoints in release logs.** Those details are removed automatically.
- **No diagnostic dumps in release builds.** A release crash leaves only a short, cleaned-up error summary.
- **Readable panels.** Settings, Career, Server Browser and pause-menu settings scale with the display.
- **Native-resolution rendering** for crisp text, HUD and gameplay in windowed and borderless modes.
- **Live windowed / borderless switching** from Settings, with no restart.
- **Custom menu backgrounds**, 2.5x font sharpness and corrected button hover/click positions.

## Includes

- Multiplayer for up to 128 players.
- Firefight for up to 16 players.
- Campaign co-op for up to 16 players.
- Forge for up to 128 players.
- Spartan/Elite Armory, career ranks, credits, commendations, challenges and service record.
- Server browser, playlists, custom games and in-app updates.

## Install

1. Download Project-Noble-v0.9.16.27-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.
