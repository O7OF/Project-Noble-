# Project Noble v0.19.65 (Closed Source)

### Non-Host Co-Op Campaign & Global Input Latency Elimination
- **Zero-Latency Observer Channel Hook:** Reverse-engineered `c_network_observer::observer_channel_send_message` (`haloreach.dll+0x3F9620`) to invoke `c_network_observer::observer_channel_send_immediate` (`haloreach.dll+0x3F95A4`) immediately whenever simulation or synchronous-action packets (`0x22`..`0x2A`) are queued. This bypasses the legacy Xbox 360 throttle timer, eliminating 16–33 ms per frame (33–66 ms RTT) of non-host input lag.
- **DirectX 11 Maximum Frame Latency = 1:** Configured `IDXGIDevice1::SetMaximumFrameLatency(1)` on the DX11 swap chain to eliminate 1–2 queued presentation frames (16–33 ms) across all modes.
- **Microsecond Clock & Non-Blocking Transport:** Enabled `timeBeginPeriod(1)` in WinMain, switched message loop polling to `MWMO_INPUTAVAILABLE`, raised UDP socket buffers to 1 MB, elevated relay threads to `THREAD_PRIORITY_HIGHEST`, and removed sleep stalls in relay loops.
- **Bidirectional UDP Verification:** NAT traversal now only latches direct UDP after a validated `PONG`, preventing dropped relay fallback when one direction is NAT-blocked.

### Server Browser & Navigation
- **US West / US East Region Alignment:** Corrected index mapping in `ServerBrowser.cpp` filter bar to align index 0 (US East) and index 1 (US West) with `kMasterRegions`.
- **Active Region Matching:** Replaced substring heuristics in the region selection modal with direct endpoint URL comparisons.

### Lobby Flow & Host Disband / Crash Handling
- **Host Leaves Match to Lobby:** Clicking "LEAVE GAME" signals `host_return_to_lobby` over WebSocket relay and HTTP API, returning the host and all connected guests directly back to the Pre-Game Lobby.
- **Host Quits or Crashes (Auto-Disband):** Quitting sends `lobby_disband` and deletes the master session. In addition, `NobleCrashHandler` and `NobleTerminateHandler` broadcast disband signals on exit, and the master server implements a 6-second grace timer upon host disconnect to auto-disband the room if the host process terminated abruptly (`Alt+F4` or crash), returning all guests to the Main Menu.
