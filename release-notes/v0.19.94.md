# Project Noble Release Notes --- v0.19.94

## Futuristic UI Polish, Scrolling & Controller Virtual Cursor
- **Rounded Halo Tactical Styling:**
  - Smoothed panel, tile, button, slider, toggle, roster, and scoreboard highlights across the front-end and pause overlays.
- **Interactive Scrollbars & Scroll Stability:**
  - Added mouse-draggable interactive scrollbars (`NobleUi::DrawInteractiveScrollbar`), pane-hovered Right-Stick scrolling, and anti-snap-back guards across pre-game map pickers, variant drawers, game options, lobby roster, server browser, mods menu, and in-game scoreboard.
- **Controller Virtual Cursor & Anti-Hop Navigation:**
  - Added toggleable Controller UI Virtual Cursor mode (`L3` quick-toggle or Settings > Controller) where the left stick steers the cursor, `A` clicks/drags, and the right stick scrolls hovered panels.
  - Added dominant-axis cone filtering and normalized `UiPad` navigation so scrolling or exiting matches never hops windows or double-triggers actions.
- **Post-Match UI Stability:**
  - Flushed lingering match input events, resynchronized controller state on match exit, and added render-thread frame ownership guards to prevent menu jitter after leaving a game.

## Networking & Join-in-Progress (JIP) Reliability
- **Anti-Boot & Connect Grace:**
  - Suppressed false engine peer-boot kicks while `NetworkTransport` relay/session transport is active across Multiplayer, Forge, Firefight, and Campaign co-op, and extended pre-session guest timeout grace.
- **Relay Broadcast & Deduplication Fixes:**
  - Tracked connected relay peers independently from pre-seeded UDP route hints, lowered packet dedupe suppression to a short 350 ms duplicate window so engine connect retries are preserved, and materialized host map variants cleanly during lobby join.
