# Project Noble Release Notes --- v0.19.92

## Full Controller & M&K UI Overhaul
- **Unified Input & Focus Consumption (`UiPad`):**
  - Added frame-scoped `AcceptPressed()`, `BackPressed()`, `ActionX()`, `ActionY()`, `TabPrev()`, `TabNext()`, and input consumption guards so closing modals, dropdowns, or sub-panels on **A / B / Enter / Esc** never double-activates or exits the parent screen.
  - Added smooth analog-stick scrolling (`AnalogScrollY`) across custom lists and tables.
- **Crisp Visual Focus Highlights (`NobleUi`):**
  - Added animated Reach-styled focus highlights (`DrawFocusHighlight`) and modern `DrawTile` primitives across menus, modals, and action buttons so controller and keyboard focus is unmistakable on every screen.
- **Pre-Game Lobby Overhaul:**
  - Added a 2-zone directional focus model linking left-side lobby options and the right-side `MY GAME SESSION` player roster (D-pad/Stick navigation, Right Stick roster scrolling, **A** to inspect player card, **B** to back out cleanly).
  - Fixed `CHANGE TEAM` double-action bug where cycling also opened the team picker dropdown.
- **Main Menu, Quit Modal, Pause Menu, Match-End UI & Scoreboard:**
  - Full controller + keyboard navigation and focus highlights on the **Quit Project Noble** modal (`YES`/`NO`), **Pause Menu**, **In-Match Settings**, **Scoreboard** (preventing immediate double-trigger into player modal), and **Match-End / Game Over** buttons.
- **Settings, Armory & Server Browser:**
  - Unified D-pad/stick repeat, **LB/RB** tab switching, right-stick scrolling, and clean `Accept`/`Back` handling across Settings, Armory, and Server Browser.
