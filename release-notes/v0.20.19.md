# Project Noble v0.20.19 Release Notes

## Overview
Project Noble v0.20.19 resolves a multiplayer customization bug where host player character colors and armor pieces were erroneously copied onto non-host players on the host's screen. All players in multiplayer sessions now consistently display their own distinct Spartan/Elite colors, armor pieces, custom visor finishes, lights, and effects across all clients.

## Highlights
- **Multiplayer Customization Isolation**: Eliminated host appearance pollution on non-host players. The host engine no longer overwrites remote player appearance records with local selections, ensuring all players display their own chosen armor permutations and colors.
- **Canonical Local Player Identification**: Replaced fragile memory address range checks (`0x2A03C00..0x2A08000`) and speculative flag inspections with direct queries against the engine's canonical `player_mapping_globals` mapping table (`pmg + 0x74`), accurately differentiating local machine datums from remote network peers.
- **Dedicated Remote Biped Color Resolution**: Remote player bipeds in multiplayer matches reliably resolve their player datums and apply replicated custom wheel RGB, visor tinting, and armor lights from their own network appearance blocks without falling back to or copying local host caches.
- **Full Customization Parity**: Spartan and Elite colors, armor pieces, visor finishes, armor lights, and effects remain strictly unique to their respective players on both host and guest screens.
