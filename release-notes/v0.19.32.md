# Project Noble v0.19.32

## Spawner Active Map Items Integration
- **Direct Active Map Items Spawning:** The Developer Cheat Menu spawner now queries and displays active match entities directly from the live Blam object pool as the primary spawning catalog.
- **Categorized Discovery:**
  - `ALL`: Complete view of all unique active tags in the current map.
  - `WEAPONS`: Live match weapons, with the local player's currently equipped Primary and Secondary weapons pinned at the top.
  - `VEHICLES`: All vehicles present in the current mission.
  - `EQUIPMENT`: Armor abilities and equipment units currently in memory.
  - `CHARACTERS`: Bipeds, AI units (Spartans, Marines, Elites, Grunts, etc.) in the match.
  - `PROPS / SCENERY`: Crates, barriers, and dynamic scenery pieces.
- **Enhanced Spawning & Giving:**
  - One-click "GIVE" automatically links live weapons directly into the player's hands via `s_unitAddWeapon`.
  - "SPAWN IN FRONT" dynamically adjusts distance and facing based on category (facing player for characters, vehicles at 5m, props/weapons at 2.5m).
  - Out-of-match state detection notifies the user to load into Campaign, Firefight, Forge, or Multiplayer.
