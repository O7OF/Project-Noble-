# Project Noble v0.20.26

## Non-Host Client Loading (All Modes & Custom Games)
- **Universal Guest Map Loading:** Resolved an issue where non-host clients were stuck loading at 0% when connecting to Multiplayer Custom Games, Forge, or Firefight. Removed the mode check that previously restricted guest initialization dispatch to campaign, allowing Command 10 (`Event: Start`) and Command 11 (`Simulation Start`) to be posted reliably for all remote joins across all game modes, whether joining in progress or launching from a pre-game lobby.
- **Robust Host Settle & Handshake:** Handshake sequencing cleanly tracks map load progress up to >= 95%, establishes sync with host simulation state, and transitions into active gameplay without stalling at the loading screen.

## Species-Specific Armor Effects (Spartan & Elite)
- **Dedicated Effect Separation:** Resolved a collision where Spartan armor effect slot (`rec[0x18]` / `block[8]`) was being overwritten by flame variant bits or brightness data. Spartan effects (Birthday Party, Heart Attack, Pestilence, Inclement Weather, Flames, Blue Flames) are now stored cleanly in `rec[0x18]` and `block[8]`, while Elite effects are stored in `rec[0x19]` / `block[9]`.
- **Flame Variant Replication:** Re-routed custom primary flame variant indices to dedicated Noble metadata slot (`block[23]` and `rec[0x1A]`), preventing any interference with native pmcg 0..6 armor effect index validation in `haloreach.dll`. Both Spartans and Elites render their authentic armor effects and custom flame colors accurately in multiplayer for both host and non-host clients.

## In-Game Armor Color Replication
- **Live Biped Color Sync:** Guaranteed that both primary and secondary armor colors (standard palette or custom RGB color wheel) are applied directly to the in-game biped object datums via `SetChangeColor` in multiplayer.
- **Remote Player Color Fallback:** Added palette color decoding fallbacks from replicated settings blocks and appearance records for remote players who choose standard palette entries rather than custom RGB wheel overrides, ensuring all player bipeds always show their correct armor colors in matches.
