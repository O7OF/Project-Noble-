# Project Noble 0.9.16.30

Visor colours fixed end-to-end: equipped finishes persist and locked finishes preview correctly.

## Highlights

- **Equipped visor colours persist.** The chosen finish is kept separately from transient Armory previews, so it can no longer fall back to Default after a click or a profile restore.
- **Locked/for-sale visor finishes preview correctly.** Click a finish to see it on the model, then buy it to equip.
- **All 30 visor finishes** use the same rank/credit unlock rules as the rest of the Armory.
- **Three-region server browser:** US West, US East and EU West (London) federated.
- **Crash-only private release log**, no release diagnostic dumps.
- **Readable scaled panels**, native-resolution rendering and live borderless switching.

## Install

1. Download Project-Noble-v0.9.16.30-win64.zip.
2. Extract the folder somewhere writable.
3. Run Noble.exe or play.bat.

Requires Windows 10/11 x64, Steam with Halo: The Master Chief Collection and the Halo: Reach DLC, and a Direct3D 11 GPU.
